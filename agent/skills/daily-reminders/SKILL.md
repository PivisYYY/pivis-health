# 待办与提醒

## 什么时候用
- 每次 `todo-add`、`project-set` 之前，先按本页定 `when`、`alarm`、`auto`、`until`。
- 老大说「提醒太多了」「别催了」「这个到点叫我」「以后都不要」。
- 老大要你「推给我」「定个闹钟」：你不推送、不建定时任务，用带 `when` 的待办卡（AGENTS 红线 7）。

## App 怎么处理这些字段（照这个设计，不要另外安排提醒）
| 字段 | App 的行为 |
|---|---|
| 有 `when`，没有 `auto` | 服务器推锁屏通知：到点前 10 分钟一条、到点一条；练习 / 打勾类过点 15 分钟还没做再催一次 |
| 没有 `when` | 只有实在定不了时间的才不写：App 时间栏显示占位「—」，不响 |
| `auto:"bedtime"` | 不响。设备识别到入睡后自动打勾，summary 写入睡时间，老大可以更正。**目前只支持 bedtime** |
| `alarm` | 只对计时卡（timer）有效：老大点「开始」后，按 `duration_min` 倒计时（没有就按 alarm 时间）响系统闹钟，静音也会响。只用于午睡、闭眼歇 |
| `until` | 过了这个点还没处理就自动收起。proposal 卡一定要写 |
| 锁屏推送 | 只由服务器发，不限条数：你每轮回复说完、待办到点前 10 分钟 / 到点 / 过点没做、你新出的要选 / 要填的卡（提议、单选、标了有话问）。每件事只推一次。你不推送（不用 `push` 命令），也不用替它安排 |

## 怎么做
1. **每条待办都写 `when`**（老大 11-08：有的有时间有的没有很乱，要统一都有；通知也跟着时间走）。
   - 拿不准就写最可能做的时间：饭的照片写饭点，称重写起床后，提议 / 复盘写老大晚上有空的时候。实在定不了才不写（App 显示占位）。
   - **钟点写进 `when`，标题里不要再写**（不要「23:15 前洗完澡」，写 `when:"23:15"`、标题「洗完澡」）。
   - 同一时刻别叠两张卡，错开 5–10 分钟。同一个板块页面上，没做完的待办最多 3 件。【每日推荐】推荐卡全天最多 5 张。
   - 老大自己要的提醒（「提醒我…」）照他说的排。
2. **老大说提醒太多**（「别催了」、`context-list --scope pref.remind` 里定了更少）：按优先级少排卡、合并卡，**不要靠去掉 `when` 让它不响**：
   1. 安全相关（clinical-safety）
   2. 进行中项目的核心卡：训练日的训练开始卡、睡前流程
   3. 其他项目卡
   4. 临时加的卡
3. **按下表定时间**：
   | 卡 | when | 其他 |
   |---|---|---|
   | 睡眠日记 | 起床 + 20 分钟 | kind=fields |
   | 咖啡截止 | 截止的钟点（如 14:00） | kind=done |
   | 睡前流程 | 最早上床 − 60 分钟 | kind=follow，一个 follow 出的视频 |
   | 上床 | 最早上床 | `auto:"bedtime"`，不响 |
   | 训练热身 | 开始 − 10 分钟 | follow，一个视频 |
   | 练完记录 | 练完的时间（开始 + 时长） | fields |
   | 称重 | 起床后 20 分钟 | number |
   | 饭的照片 | 饭点（按老大的作息，午饭、晚饭各一个） | fields，photo |
   | 呼吸练习 | 老大选的时间 | follow，一个视频 |
   | 提议、复盘 | 老大晚上有空的时候（如 21:00） | proposal，写 until |
   | 午睡、闭眼歇 | 老大定的时间 | timer，`alarm` = 开始 + 时长 |
4. **时段**：会响的卡不排在 `pref.remind` 里老大说别打扰的时段，也不排在 00:00–08:00。老大自己定的睡前流程、起床后的日记除外。
5. **提醒还是闹钟**：要老大「记得做」的用 `when`（通知可以忽略）。必须准时停下来的（午睡结束）用 `alarm`。早上起床不用 `alarm`，请老大用手机自己的闹钟。
6. **自动打勾优先**：设备能识别的（现在只有入睡），用 `auto`，不让老大手动点。训练、步数还不能自动打勾，用记录卡。
7. **文字**：title 不超过 14 个字，写要做的事。note 不超过 16 个字，只写有信息量的一句（「在床外做，床只用来睡」），不写操作说明（「做了就点一下」）。

## 错过了怎么办
- 服务器会自动再催一次（练习 / 打勾类，过点 15 分钟），**你不再催**。
- 过期或跳过的卡：不补到今天，不加补偿任务。第二天按 habit-coach 的「不连续漏两次」处理。
- 例外：安全相关的事（比如老大说过胸闷、要复诊），可以在对话里再说一次。

## 排提醒前先看执行情况（remind-stats）
给重复做的事定时间、改时间、加提醒之前，先跑 `./pivis-health remind-stats`，看这一项（同一个项目模板，或同一个标题）以前怎么样：
- `rate` 低于 40% 且 `n` ≥ 5、`typical` 比提醒晚 30 分钟以上：老大实际是那个时候才做。新排或重排这一项时，时间写 `typical`（项目模板用 project-set 改 `when`），在回复里说一句「你一般 23:40 才开始，我把提醒放到那时」，老大说不要就改回。
- `ignored_streak` ≥ 3：最近连续 3 次没动。不再给这一项加新提醒，也不催；用 options 卡问一次「这个还要吗：换个时间 / 换短版 / 先停掉」，停掉要老大点。
- 「你已经了解到的老大」里有 `learn.remind.*`（洞察确认过的提醒规律）：照它排，不要再排回已经证明不管用的时间。
- 只有挪时间、换短版可以先做再说；停掉提醒、改内容照旧确认。

## 洞察里的提醒调整（先改后说）
- 洞察发现某个提醒管用得不好（比如提醒后多半一小时才动手），服务器会在老大点开那段话时**先把提醒挪好**，那一点里写「我先把提醒挪到 22:00，不合适回一句我就改回」。老大说「改回去」，你就按 insight skill 改回原来的时间，回 receipt。
- 只有**挪时间、换形式**可以先改后说；**停掉提醒**、去掉 `when`、改项目内容，照旧 plan 卡确认。

## 老大说「算了」「以后都不要」
- 「算了」：按 AGENTS 红线 5（这张标 skipped，今天同类的去掉 `when`）。要改时间就 `todo-update --id <id> --json '{"when":"21:30"}'`，只改这一张。
- 「以后都不要」：`context-record --scope pref.remind`，payload 写进 rule，再 project-set 去掉对应模板的 `when` 或整项。附 receipt。

## 提前提醒和闹钟（服务器和手机怎么响）
- **待办的 `when` 写真正要做的时刻**，标题不写时间，**不要为了提前提醒把时间往前挪**。服务器会在到点前 N 分钟推一条（N = `pref.remind` 的 `lead_min`，默认 10），到点再推一条，练习和打勾卡过点 15 分钟没做再催一次。
- 老大说「提前 X 分钟提醒我」「不要提前提醒」：`context-record --scope pref.remind`，payload 写 rule 并带 `"lead_min": X`（不要提前就是 0），**不改任何卡的时间**。
- 计时卡（timer）：老大点「开始」后，手机定一个系统闹钟（静音也响）；卡上写了 `alarm`（几点叫你）就定在那个时刻，没写就按开始 + `duration_min`。服务器在同一时刻再推一条带声音的「时间到了」兜底。所以午睡、泡脚这类要准点叫的，写 `alarm`。

## 规则与红线
1. 上限只按「怎么做」第 1 步。
2. 每张卡最多一次到点提醒 + 一次 App 自动催，不加第三次。
3. 你不推送、不建定时任务（AGENTS 红线 7）；「算了」按 AGENTS 红线 5。
4. 老大定过：勿扰和开车时不打扰。不要设计开车时响的卡。

## 模板
到点提醒（会响）：
```json
{"board":"sleep","when":"23:30","title":"床外拉伸","kind":"follow","note":"在床外做，床只用来睡",
 "media":{"kind":"video","title":"睡前拉伸 · 10 分钟","url":"/media/follow/<ssid>/out.mp4","duration_min":10}}
```
不响的记录卡：
```json
{"board":"life","title":"早上称一下","kind":"number","note":"空腹、上完厕所",
 "inputs":[{"id":"kg","label":"体重","type":"number","unit":"kg","submit":"agent"}]}
```
设备自动打勾：
```json
{"board":"sleep","when":"00:30","title":"00:30 后再上床","kind":"done","auto":"bedtime","note":"困了再上床"}
```

## 成长
- `pref.remind`：`{"rule":"每天最多 2 次提醒，上午工作时不打扰","max":2,"quiet":["上午工作时"]}`。
- `learn.remind`：哪个时间点的卡老大最常做、最常跳过。例：`{"rule":"21:00 的卡常过期，22:30 的能做到","evidence":"近 2 周 todo-list"}`。下次排时间先看这条。

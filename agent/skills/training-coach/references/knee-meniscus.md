# 膝关节 · 半月板损伤的保守训练

`sport.preference` 或 `profile.safety` 里记着半月板损伤、膝盖疼、医生让「练肌肉、保守治疗」时，**排任何下肢动作、挑任何训练视频之前先读这一页**。医生说的永远优先（`profile.doctor`）；这里是医生没细说时的专业默认。不诊断，不说「你是 X 级撕裂所以……」，只说怎么练、哪些先不做、出现什么要复诊。

证据等级同 cbti 的 sleep-science.md：A 指南或多 RCT 一致，B 单项研究，C 经验或机制。

---

## 1. 背景（解释给老大听时用一两句）

- 半月板是膝关节里的软骨垫，负责分散压力、稳定关节。核磁的「1–3 级」是信号分级：**2 级 = 半月板内部有信号、还没到关节面**，通常不需要手术，以训练为主。
- 对非急性的半月板损伤，**系统训练和关节镜手术相比，两年后疼痛和功能差不多**，训练组大腿力量更好 [1][2]。所以「练对肌肉」本身就是治疗，不是辅助。
- 半月板受力最大的三种情况：**负重下膝盖弯得很深**（超过约 90°，越深压力越大）[3]、**脚踩住地面时膝盖扭转**（急停转身、单脚转体）、**落地冲击**（跳、跑下坡）。训练和打球的安排都围绕「先避开这三样，逐步加回来」。

## 2. 要练什么（目标肌群和为什么）

| 肌群 | 作用 | 代表动作（先易后难） |
|---|---|---|
| 股四头肌（尤其股内侧） | 吸收冲击、控制膝盖不晃，最重要 | 坐姿 / 仰卧收紧大腿（股四头肌等长）→ 直腿抬高 → 靠墙静蹲（膝 45–60°）→ 浅蹲（0–60°）→ 低台阶上台阶 → 西班牙蹲（弹力带）|
| 臀中肌、臀大肌 | 防止膝盖内扣（扭转时最伤半月板） | 臀桥 → 侧卧抬腿 → 弹力带侧走 / 蚌式 → 单腿臀桥 |
| 腘绳肌 | 和股四头肌一起稳膝 | 臀桥走步、弹力带腿弯举、轻的罗马尼亚硬拉（膝微屈） |
| 小腿 | 落地缓冲 | 双脚 → 单脚提踵 |
| 平衡 / 本体感觉 | 打球时急停变向的控制 | 单腿站 30 秒 → 闭眼 → 软垫上 → 单腿站 + 手上抛接 |
| 核心抗旋 | 转体发力来自髋和躯干，不是膝盖 | 死虫、平板、Pallof 推 |

每周 **3–4 次**康复向力量（可以每次 15–25 分钟），比一周一次大课有效 [1]。每个动作 2–3 组 × 10–15 次，慢、可控，**最后 2–3 次有点吃力但姿势不走样**（RIR 2–3）。

## 3. 动作红绿灯

| 灯 | 动作 | 说明 |
|---|---|---|
| 绿：可以做 | 直腿抬高、股四头肌等长、臀桥、侧卧抬腿、蚌式、弹力带侧走、小腿提踵、靠墙静蹲（45–60°）、浅蹲（0–60°）、低台阶上台阶（10–20 cm）、固定单车（低阻力）、游泳自由泳、平地快走 | 疼痛按第 4 节监控 |
| 黄：有条件 | 深一些的蹲和弓步（只到 90°，不疼才加深）、分腿蹲（前膝不过脚尖太多、不内扣）、侧弓步（幅度小）、腿屈伸器械（只做 90°→30° 的范围）、慢跑（平地、无痛再开始） | 第 2 阶段以后；任何一项疼 >3/10 就退回 |
| 红：先不做 | 负重深蹲到底、全蹲、跪坐、盘腿坐；跳跃和落地（开合跳、跳箱、跳绳）；单脚踩地扭转（转体弓步、高抬腿转体）；蛙泳蹬腿；急停变向、比赛强度网球 | 直到医生同意、或第 5 节回场标准都达到 |

**挑跟练视频时逐个动作过这张表**：视频里只要有一个红灯动作，就不能直接用。按 follow-video skill 剪掉那个动作（`session rm-move`），或换片；并在对话里说清「第几个动作是 X，会让膝盖 Y，我剪掉了」。常见的「坑」：热身里夹着开合跳、高抬腿；拉伸里有跪姿股四头肌拉伸（改站姿）；「膝关节训练」视频里有深蹲跳。

## 4. 疼痛监控（决定加量还是退）

用 0–10 分疼痛评分（运动中、当晚、第二天早上各看一次）[4]：

| 情况 | 怎么做 |
|---|---|
| 运动中 ≤ 3/10，第二天早上回到平时水平 | 可以，下次照做或按计划加一点 |
| 运动中 > 3/10，或第二天早上更疼、更僵 | 这个动作退一级（幅度、重量或次数减），48 小时后再试 |
| 练完膝盖**肿**了 | 那天的量太大：下次减半，肿消了再慢慢加 |
| 卡住（膝盖突然锁住伸不直）、打软腿（突然没劲要跪）、明显肿胀反复、夜里疼醒 | **停下肢训练，尽快复诊骨科或运动医学科**（clinical-safety「尽快」级） |

## 5. 分阶段（每一阶段达标才进下一阶段，没有固定天数）

| 阶段 | 目标 | 内容 | 进下一阶段的标准 |
|---|---|---|---|
| 1 消肿控痛 | 走路、上下楼不疼 | 第 2 节绿灯里最轻的；单车；冰敷可选 | 日常活动疼痛 ≤ 2/10，没有肿 |
| 2 力量 | 两腿力量接近 | 绿灯全部 + 黄灯里的浅蹲、上台阶；每周 3–4 次 | 单腿站 30 秒稳；单腿浅蹲（60°）10 次膝盖不内扣、不疼 |
| 3 动态 | 能控制减速、侧向 | 侧向小步、慢速变向、低强度跳（双脚原地小跳，先不单脚）、慢跑 | 慢跑 20 分钟不疼；侧向移动、减速不疼，第二天不肿 |
| 4 回场 | 回到网球 | 第 6 节的回场顺序 | 医生同意；比赛强度打完第二天不疼不肿 |

## 6. 网球回场顺序

1. 原地挥拍、喂球（不跑动）→ 2. 底线对拉、短时间（20–30 分钟）→ 3. 加跑动和截击 → 4. 发球和高压 → 5. 练习赛 → 6. 正式比赛。
- 每一步至少 2–3 次没问题再进下一步；一周比赛强度不超过 2 次，中间隔一天。
- 打球当天热身必须有膝盖和臀的激活（臀桥、侧走、浅蹲），不用跳跃热身。
- 鞋要有侧向支撑；红土 / 软场地比硬地对膝盖友好；打完那天不再排下肢力量。

## 7. 和其他计划的配合

- 康复动作属于「低强度」，晚上做没问题，离睡觉 1 小时以上即可（见 cbti 的 sleep-science.md）。
- 康复训练日可以和上肢、核心练习放在同一天；和高强度网球不放同一天的后段。
- 减脂期间（GLP-1 类药物等）力量训练更重要，保住肌肉，参见 weight-nutrition。

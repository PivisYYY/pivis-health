# 训练教练

## 什么时候用
- 老大说「今天打球」「想练力量」「能不能跑」「帮我排个训练计划」。
- 练完的记录卡【待办提交】（RPE、哪里不舒服）。
- project-list 里有训练项目（`board=sport`），周日早上做本周复盘时。
- 老大说哪里疼：**先看本页「伤病红旗」**，再看 clinical-safety。

每次课该练什么（用来挑已有的视频，或告诉老大该找什么样的博主视频）、各项目怎么加量、项目 JSON 都在 `references/sessions.md`。每次课在卡上只是「这个项目 + 一个视频」，视频只认 follow 出的片，不写文字步骤（AGENTS 红线 9）。

## 怎么做

### 1. 今天能练多重（每次都先判断）
跑 `./pivis-health facts`，看 `recovery_zone`、`recovery_pct.today`、`hrv_trend.change_pct`、`strain.recent`（昨天的负荷）、`last_night.short_h`。
| 档 | 条件（命中任意一条就算） | 今天怎么练 |
|---|---|---|
| 收 | `recovery_zone=red`；或 `hrv_trend.change_pct ≤ -15`；或 `last_night.short_h ≥ 2`；或老大说发烧、全身酸痛、胸闷、拉肚子 | 只做轻的（RPE ≤ 4）：走路、灵活性、技术练习，≤ 30 分钟；或者休息。发烧和胸闷的话不练 |
| 稳 | `recovery_zone=yellow`；或昨天的负荷 ≥ 18；或只有鼻塞、流涕这类脖子以上的轻症状 | 照计划练，但不加量。RPE 上限 7，不做极限测试，不打比赛强度 |
| 冲 | `recovery_zone=green`，上面两档都没命中 | 按计划练，今天可以安排重课或加量 |
| 没数 | facts 里没有恢复数据 | 用 question 卡问「今天身体感觉 1–5」：≤2 收，3 稳，≥4 冲 |
- 回答格式按 phealth-role 的三段：结论（今天哪一档）→ 依据（抄 facts 的数和日期）→ 规矩（多久、多重、RPE 上限）。
- 数字只抄 facts；facts 里没有的就说「这项最近没有数据」。

### 2. 单次活动（老大说今天要打球、跑步）
照 AGENTS 第 4 节「常见流程」：一句回应加一个必要提醒（来自第 1 步）→ question 卡问几点开始、多久 → plan 卡 → 写热身视频卡和练完记录卡 → receipt。
热身视频按项目挑（该有什么看 sessions.md 第 1 节），不要每次都用网球的；`follow session list` 里没有这项运动的热身片，就只写练完记录卡，并请老大发一个博主热身视频（按 follow-video 的「还没有视频」）。老大打网球：专项力量（肩袖、前臂离心、抗旋、侧向移动）的动作库和 8 / 20 / 25 分钟三种视频见 `references/tennis.md`。

### 3. 长期计划（项目）
1. 先 `context-list --scope sport.preference` 看项目、频率、时间、伤病。缺的用 question 卡补。
2. 按 sessions.md 第 3 节选结构（每周几次、哪几天），用 plan 卡确认：哪几天、每次多久、每次跟哪个视频、加量规则（写进 rules）。每一课要有一个 follow 出的视频；还缺的，先请老大发博主视频，出好片再排那一课。
3. 「就这样」后 `project-set`（每一课一个视频，训练日用 `weekdays`），附 receipt。
4. 训练日早上那次【每日推荐】（顺带做每日整理）时按第 1 步判断。「收」档就把当天训练卡改轻：有灵活性或拉伸的 follow 视频，`todo-update` 换成它（只写新的 `media`），note 写「今天恢复偏低，只做灵活性」；没有就把这张改成 `{"status":"skipped","summary":"恢复偏低，今天不练"}`。都在对话里说一句。

### 4. 练完记录（RPE）
- 记录卡的 inputs：整体多累（RPE 1–10）、哪里不舒服（multi）、完成度；力量训练再加「最后一组还能做几个」。
- 收到【待办提交】：`todo-update` 写 `{"status":"done","summary":"RPE 7 · 全做完 · 肩有点紧","record":{"values":<原样抄>}}`。
- 选了身体某个部位：用 question 卡追问一句「疼的程度 0–10，明早还疼吗」，再按「伤病红旗」处理。
- RPE 比计划高 2 以上，或完成度「一半以下」：记进 `learn.training`，下次同一课不加量。

### 5. 加量、减量、漏练
| 情况 | 规则 |
|---|---|
| 力量：每组都做到次数上限，且最后一组还能做 ≥ 2 个 | 下次加重：上肢 +2.5 kg，下肢 +5 kg（或者每组 +1 次） |
| 力量：连续 2 次做不到次数下限 | 降 5–10% 重量 |
| 跑步 | 每周总量最多 +10%。80% 的时间用能说完整句子的速度跑。每周最多 1 次快跑 |
| 网球 | 一周比赛强度不超过 3 次。每周 2 次肩袖和前臂离心练习，防肩肘劳损 |
| deload（减量周） | 每 4–6 周一次；或者连续 2 次同样重量 RPE 涨 ≥ 2；或者 7 天里有 ≥ 3 天 `recovery_zone=red`；或者酸痛、睡眠持续变差。做法：组数减半，重量 −10%，次数和频率不变，持续一周 |
| 漏练 1 次 | 不补双倍。离下一次重课还有 ≥ 48 小时就挪到明天，不然就放掉 |
| 连续漏 2 次 | 下一次只做「最低版」（一半的量），先把节奏接上（habit-coach 的「不连续漏两次」） |
| 停了 ≥ 1 周 | 从上次的 70% 重新开始，两周内回到原来的量 |
- 重量和次数只用老大自己记的（记录卡、对话里说的），不编。
- 加量、减量写进 plan 卡，老大确认后再 project-set。周中不改结构，只按第 1 步当天改轻。

## 伤病红旗（出现就停练，不继续给训练建议）
| 症状 | 动作 |
|---|---|
| 胸痛或胸闷、异常气短、头晕或晕倒、运动中心跳乱 | 立刻停。症状不缓解就打 120。按 clinical-safety 处理 |
| 尖锐的刺痛、有「啪」的一声、马上肿起来、关节卡住或打软、走路变形 | 停练这个部位，冰敷、抬高，24–48 小时内去骨科或运动医学科 |
| 麻、刺痛、无力 | 停练，尽快去看医生 |
| 夜里或休息时也疼；疼了超过 3 天不见好，或者越来越重 | 停练这个部位，去看医生 |
| 运动中疼痛 ≤ 3/10，第二天早上就好了 | 可以继续，但这个动作不加量 |
| 运动中疼痛 > 3/10，或者第二天更疼 | 这个动作减量或者换掉；再犯就去看医生 |
- 运动后 1–3 天两边对称的钝痛、动一动会好，是延迟性肌肉酸痛，不用停，当天降一档就行。
- 不判断伤的是什么（不说「是网球肘」），只说「这种疼要停，去骨科或运动医学科看看」。

## 规则与红线
1. 恢复、HRV、负荷、睡眠的数字只来自 `facts`、`compare`、`viz`。
2. 不诊断伤病，不推荐止痛药、膏药的剂量。
3. 在用 GLP-1 类药物减重时，力量训练是保肌肉的重点，每周至少 2 次。剂量的事不评价。
4. 一个训练日最多两张会响的卡：热身或训练开始一张，练完记录一张（项目里的记录卡默认不写 when）；都算进 daily-reminders 的上限。
5. 老大说「算了」：按 AGENTS 红线 5。

## 模板
单次打球见 AGENTS 第 4 节。力量、跑步、灵活性项目的 JSON，和热身、训练、放松视频里该有什么，见 `references/sessions.md`。

## 成长
- `sport.preference`：项目、频率、时间段、伤病部位、器械条件（家里还是健身房）。
- `learn.training`：`{"rule":"打完网球第二天恢复常在黄区，第二天不排力量","evidence":"近 4 次球后第二天 recovery_zone 3 次 yellow（facts）"}`。
- 每次复盘都记下各课目前的重量和次数（`sport.loads`，用老大记的数），下次加量就从这里接着来。

# 肘

老大说肘外侧 / 内侧疼、反手或正手疼、拧毛巾或提东西疼、握拍没劲、手指麻时读这一页。流程在 `../SKILL.md`，通用原理在 `principles.md`，网球专项（前臂离心、肩肘预防）在 `../../training-coach/references/tennis.md`。
证据等级：A 指南 / 荟萃分析，B RCT / 队列，C 共识 / 经验。

## 2. 分型和怎么区分

| 类型 | 典型表现 | 怎么区分 | 方向 | 等级 |
|---|---|---|---|---|
| 肘外侧伸腕肌腱负荷型（最常见，多在 35–55 岁） | 肘外侧骨头前下方一点疼；握拳、拧、手心朝下提东西、反手重；早上僵、热身后好些 | 用力翘手腕（手背朝上往上抬）或用力伸直中指时疼；握力比另一侧弱且疼 | 渐进负荷是主线；一年内多数自己好，但训练好得更快、复发少 [1][2][3] | A–B |
| 肘内侧屈腕肌腱负荷型 | 肘内侧骨头前下方疼；正手上旋、发球、手心朝上提东西重 | 用力屈手腕或前臂往里转时疼 | 同外侧思路，证据少（照外侧方案推） | C |
| 尺神经受刺激型 | 肘内侧到无名指、小指麻刺；长时间屈肘（打电话、枕着手睡）加重 | 屈肘久了小指麻；敲肘内侧后面一条沟会过电 | 避免长时间屈肘和压肘；夜里屈肘睡可用毛巾松松裹住保持微屈；麻木无力加重转诊 | C |
| 前臂深处神经受刺激型 | 前臂外侧深处（离骨头下方 4–5 指）酸痛，肌腱方案效果差 | 按压疼点在肌腱疼点下方几指；手腕伸直抗阻不太疼 | 减少反复旋前旋后；门诊康复医学科 | C |
| 肘后侧负荷型 | 发球伸直到底那一下肘后面疼 | 用力伸直到底时疼 | 减发球量，练三头肌离心，查发球技术 | C |
| 颈部牵涉 | 转头、低头引出肘疼；手指麻；肘局部按压不太疼 | 动脖子引出 | 按 neck.md | C |
| 急性外伤 | 摔、撞后变形、伸不直；或「啪」一声后肘前面淤青、上臂鼓包 | 有受伤那一下 | 尽快骨科（肘前面的肌腱断裂有手术时间窗） | C |

## 3. 红旗和转诊
| 情况 | 级别 | 去哪 |
|---|---|---|
| 肘红肿热，伴发烧 | 急 | 急诊 |
| 外伤后变形、不能伸直或弯曲，骨头上按着剧痛 | 尽快（今天） | 急诊 / 骨科 |
| 提重物时肘前「啪」一声，之后淤青、上臂肌肉往上缩成鼓包、转手心无力 | 尽快（1–2 周内要见到医生） | 骨科 |
| 手麻范围扩大、手没劲、小肌肉变瘦 | 尽快 | 手外科 / 神经科 |
| 认真练 12 周仍明显影响生活和打球 | 门诊 | 运动医学科 / 康复医学科 |
- 医生建议打针（封闭）或 PRP：不评价，请老大问医生「短期和一年后的效果分别怎样」。研究里打针短期见效但一年时结果反而差、复发多 [2][4]，所以无论打不打，负荷训练都是主线。

## 4. 动作红黄绿（肘外侧为主；内侧把「伸腕」换成「屈腕」、手心方向反过来）
| 灯 | 动作 | 说明 |
|---|---|---|
| 绿（加载期起） | 伸腕等长（手背朝上，另一只手或桌沿挡住，中等用力）、握力球轻握、前臂旋前旋后（不负重 / 轻）、手腕活动度、肩胛和肩袖力量（tennis.md 肩部动作） | 疼 ≤ 3 |
| 黄（力量期起） | 伸腕慢速（哑铃或水瓶，3 秒上 3 秒下）、伸腕离心（另一只手帮着抬上去、慢放 3–4 秒）、扭力棒反向扭（「泰勒扭」）、握力训练、锤式弯举、前臂旋转（锤柄加长力臂） | 疼 ≤ 3–5，第二天早上回到平时 |
| 红（刺激期先不做） | 手心朝下的大重量（正握引体、正握划船重、反握弯举）、宽握大重量卧推推起时死抓杠、反手和发球的数量照旧、比赛 | 回归期按第 6 节加回 |
- 握着东西「手背朝上 + 伸腕 + 用力」最刺激外侧；日常改成手心朝上提东西、双手拿（C）。

## 5. 分阶段方案（肘外侧）
| 阶段 | 视频里该有的 | 量 | 频率 | 进下一阶段 |
|---|---|---|---|---|
| 加载（1–3 周） | 伸腕等长、握力球轻握、手腕活动度 | 等长 5 × 30–45 秒（中等用力，疼 ≤ 3） | 每天 1–2 次 | 7 天绿灯；握拳和提轻物（水杯、包）疼 ≤ 2 |
| 力量（4–12 周） | 伸腕慢速 / 离心、扭力棒反向扭、旋前旋后、握力、肩袖和肩胛 | 3 × 15 慢速（离心 3–4 秒），负荷逐周加到 3 × 8–10 | 离心 / 扭力棒每天或隔天；整体每周 3 次 | 握力达到健侧 90%、用力伸腕 / 伸中指几乎不疼；第 6 节前 2 条 |
| 回归 | 快速握放、前臂快速旋转（轻）、底线对拉阶梯 | 2–3 × 15–20 秒 | 每周 2–3 次 | 第 6 节全部 |
| 维持 | 前臂离心（8 分钟肩肘预防，tennis.md） | 2 × 15 | 每周 2 次 | — |
- 扭力棒反向扭加进常规治疗，明显改善疼痛和力量 [5]（B）；离心整体有效但方案差异大 [6]（A–B）。
- 前臂护带（加压带）可以在打球、搬东西时用，只有短期作用（C）。
- 疼 3 个月以上的，很少只靠一个动作好：教育 + 改负荷 + 渐进力量 + 肩胛和肩袖 [1]（A–B）。

## 6. 回到网球
**标准**：握力 ≥ 健侧 90% 且不疼；用力伸腕 / 伸中指疼 ≤ 1；伸腕慢速 3 × 10（中等重量）第二天不加重；底线对拉 60 分钟第二天早上不加重。
**阶梯**（每步 2–3 次没问题再进）：
1. 正手底线对拉 20 分钟 → 2. 加反手（双手反手的先恢复；单手反手最后）→ 3. 截击 → 4. 发球（同 shoulder.md 第 6 节）→ 5. 练习赛 → 6. 比赛。
**器材和技术**（C 级为主）：
- 握把太细要攥得更紧：握把以握住后指尖和掌根之间能放进另一只手的一根食指宽为宜。
- 线磅偏高、球拍太硬、球太旧太重，都让前臂多扛：先降几磅、换软一点的线。
- 单手反手「手腕先动、击球点靠后」最伤外侧：建议请教练看；康复期可先用双手反手。
- 打完当晚记一次 0–10（打完记录卡选了肘就问）。

## 7. 日常
- 鼠标：手腕放平、别翘着；鼠标靠近身体；每 30–45 分钟松一松手（C）。
- 提东西手心朝上、双手拿、靠近身体；拧瓶盖、拧毛巾先用另一只手（C）。

## 8. 请老大找视频时怎么说
- 加载期：「肘外侧康复入门：伸腕等长、握力球，动作慢，一个人出镜，5–6 分钟。」
- 力量期：「网球肘康复：哑铃伸腕离心、扭力棒反向扭、前臂旋转，一个人出镜，8–10 分钟。」（对老大说找视频时可以用「网球肘」这个搜索词，但不对他下这个判断。）

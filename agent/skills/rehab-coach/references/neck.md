# 脖子（伏案、颈肩）

Psir 说脖子疼、僵、落枕、颈肩酸、伏案一天脖子受不了、头后面疼、手臂窜麻时读这一页。流程在 `../SKILL.md`，通用原理在 `principles.md`；手臂疼为主的也对照 `shoulder.md`、`elbow.md`。
证据等级：A 指南 / 荟萃分析，B RCT / 队列，C 共识 / 经验。

---

## 1. 问诊要点（第二轮 question 卡）
```json
[{"id":"worse","label":"什么时候更疼","type":"multi","options":["久坐看屏幕","低头看手机","转头 / 抬头","早上起床","压力大、睡得少时"]},
 {"id":"spread","label":"疼会不会","type":"multi","options":["只在脖子和肩上","连到后脑勺头疼","窜过手肘到手","手指麻","都没有"]},
 {"id":"onset","label":"怎么开始的","type":"options","options":["睡一觉起来就疼","慢慢累积","撞了、摔了、车祸后","说不清"]},
 {"id":"other","label":"有没有","type":"multi","options":["头晕、看东西重影","手变笨、走路不稳","两只手都麻","都没有"]}]
```
- 第四题前三项任意 → 第 3 节红旗。「撞了、摔了、车祸后」→ 先按 Canadian C-spine 规则判断要不要拍片 [1]（有危险机制、年龄 ≥ 65、手脚麻木、不能左右转头 45° 都要去医院）。
- 还要问：一天坐多久、显示器高度、笔记本还是外接屏、手机用多少、最近工作压力和睡眠。

## 2. 分型和怎么区分（按颈痛指南的分类 [2]）

| 类型 | 典型表现 | 怎么区分 | 方向 | 等级 |
|---|---|---|---|---|
| 活动受限型（最常见，伏案、落枕） | 脖子和肩上疼，某些方向转不动；不窜到手 | 转头、低头、仰头某个方向受限，疼局限在颈肩 | 动起来 + 颈肩力量；手法可作短期辅助 [2][3] | A |
| 伴头痛型 | 后脑勺或一侧头疼，跟脖子姿势、活动相关，脖子动一动会引出 | 头痛先有脖子疼，转头引出同侧头痛 | 深层颈屈肌和肩胛训练 + 手法 [4] | B |
| 神经相关型（手臂窜痛） | 手臂疼比脖子重，过肘到手，手指麻；仰头、转向痛侧加重；把手放在头顶反而舒服 | 仰头 + 转向痛侧引出手臂症状 | 让症状往脖子中间收的姿势、神经滑动、颈肩力量；多数几周到几个月好转；无力加重转诊 [2] | B–C |
| 挥鞭伤后（车祸、撞击） | 撞击后脖子疼僵，可能头晕、注意力差 | 有撞击史 | 先排除骨折（C-spine 规则），之后尽早恢复活动 + 运动 [2] | B |
| 敏化型 | 超过 3 个月，范围扩散，压力大、睡差时更重 | 疼和姿势、时长对不上 | 疼痛教育 + 运动 + 睡眠和压力（stress-recovery） | B |
| 严重问题 | 见第 3 节 | — | 转诊 | — |

## 3. 红旗和转诊
| 情况 | 级别 | 去哪 |
|---|---|---|
| 脖子疼伴头晕、重影、说话含糊、吞咽困难、走路不稳、一侧脸或身体麻、突然剧烈头痛 | 急 | 120 |
| 外伤后脖子疼且符合 C-spine 规则要拍片的任意一条 | 尽快（今天） | 急诊 |
| 手变笨（扣扣子、写字变差）、走路发飘、两手或四肢都麻、大小便变化 | 尽快 | 脊柱外科 / 神经科 |
| 手臂进行性无力、肌肉变瘦 | 尽快 | 脊柱外科 / 神经科 |
| 发烧伴脖子硬、意识不清 | 急 | 120 |
| 有肿瘤史、夜里不动也疼、体重莫名下降 | 尽快 | 骨科 / 内科 |
| 晨僵 > 30 分钟、多处关节疼 | 门诊 | 风湿免疫科 |
| 手臂疼认真处理 6 周不见好 | 门诊 | 脊柱外科 / 疼痛科 / 康复医学科 |
- 没有红旗不需要拍片；片子上的「颈椎退变、生理曲度变直」在没疼的人里也很常见，不要据此吓唬 Psir（principles 第 10 节）。

## 4. 动作红黄绿
| 灯 | 动作 | 说明 |
|---|---|---|
| 绿 | 收下巴（点头式，深层颈屈肌）、颈部各方向缓慢活动、肩胛后下收、弹力带划船、肩外旋、胸椎伸展（坐姿靠椅背、泡沫轴）、走路 | 疼 ≤ 3 |
| 黄（力量期） | 哑铃耸肩、俯身反向飞鸟、单臂划船、侧平举（拇指朝上、不过 90°）、俯卧 Y / T、颈部等长（四个方向手挡住头） | 疼 ≤ 3，第二天早上回到平时 |
| 红（刺激期先不做） | 颈后推举、颈后下拉、头倒立、「颈椎操」里的大幅快速绕圈、用手大力往下压头拉伸、神经型时仰头到底和转向痛侧到底 | 「落枕」后别让人猛扳脖子 |
- 审视频常见的坑：「颈椎放松」里的快速大幅绕头、手压头往下拉；「肩颈训练」里的颈后下拉。

## 5. 分阶段方案
| 阶段 | 视频里该有的 | 量 | 频率 | 进下一阶段 |
|---|---|---|---|---|
| 保护（落枕、急性 1–3 天） | 小幅度各方向活动、热敷后收下巴、肩胛后收 | 每个 5–10 次，每次 3–5 分钟 | 每天 3–5 次 + 每 30 分钟动一下 | 转头基本能转，疼 ≤ 3 |
| 加载（1–3 周） | 收下巴保持、颈部活动度、肩胛后下收、弹力带划船、胸椎伸展 | 收下巴 10 × 10 秒；划船 3 × 15 | 每天 10 分钟 | 7 天绿灯；伏案 1 小时疼 ≤ 2 |
| 力量（4–12 周） | 耸肩、反向飞鸟、单臂划船、侧平举、颈部等长、俯卧 Y / T | 3 × 8–12，RIR 2–3 | 每周 3 次 × 20 分钟（办公室颈肩痛的经典有效方案）[5] | 一天工作结束疼 ≤ 2；颈部等长不疼 |
| 维持 | 颈肩力量并进全身力量课；工作中每 30–45 分钟动 1–2 分钟 | — | 每周 2–3 次 | — |
- 针对颈肩的力量训练比一般有氧更能减轻伏案颈肩痛 [5]（B）；颈部运动整体有效 [3]（A）。
- 伴头痛型：深层颈屈肌（收下巴）和肩胛训练连续 6 周，头痛次数和强度下降 [4]（B）。
- 神经型：神经滑动（不拉紧，来回轻动）、颈肩力量；症状往脖子中间收是好转。

## 6. 回到运动
- 网球、力量：转头各方向不疼；颈部等长和力量期动作不疼；打完第二天不加重。发球仰头那一下引出手臂窜痛 → 神经型，先不发球。
- 游泳换气、骑车长时间抬头（低把位）会加重颈部负荷，逐步加时长（C）。

## 7. 伏案和睡觉
| 做法 | 证据 | 等级 |
|---|---|---|
| 没有「唯一正确的坐姿」，关键是常换、别一个姿势待太久 [6] | 「坐直」本身不能防颈痛 | C |
| 每 30–45 分钟起来动 1–2 分钟（转头、耸肩、扩胸、走几步） | 打断持续负荷 | C |
| 显示器上沿大约齐眼、一臂远；笔记本长时间用要加外接键盘或支架 | 减少长时间低头 | C |
| 手机举高一点看，少长时间低头 | 同上 | C |
| 枕头让脖子保持中立（侧睡高一点、仰睡低一点）；没有哪种「颈椎枕」证据更好 | — | C |
| 压力大、睡得少时颈肩痛更重 [7] | 一起管睡眠和压力 | B |
- 这些是改环境，不是练习：不用写成待办，跟 Psir 说一次，必要时记 `life.work` 或 `learn.rehab`。

## 8. 请 Psir 找视频时怎么说
- 加载期：「伏案颈肩放松和激活：收下巴、肩胛后收、弹力带划船、胸椎伸展，动作慢，一个人出镜，8–10 分钟，不要快速绕头和手压头。」
- 力量期：「颈肩力量：哑铃耸肩、反向飞鸟、单臂划船、侧平举，一个人出镜，15–20 分钟。」

# 康复原理（康复师的底层逻辑）

给任何伤痛建议、定阶段、定剂量、判断能不能回场之前先读这一页。流程（红旗 → 问诊 → 分型 → 阶段 → 疼痛卡 → 复盘）在 `../SKILL.md`；各部位的分型、动作红黄绿、方案和回场标准在同目录的部位文件。

证据等级：**A** 指南、系统综述 / 荟萃分析结论一致；**B** 单项 RCT 或较强的队列研究；**C** 专家共识、机制或临床经验。C 级要跟 Psir 直说证据弱。

---

## 1. 负荷—能力模型（为什么会疼、为什么练能好）

| 要点 | 说明 | 等级 |
|---|---|---|
| 疼多半是「负荷超过了这块组织此刻的能力」 | 不是只看负荷大小，而是看**负荷变化的速度**：突然加量（多打一场、换拍、开始跑坡、搬家）比长期大量更容易出问题 [1][2] | B |
| 负荷比值只是参考 | 「急性 / 慢性负荷比」（近 1 周 vs 近 4 周）曾很流行，但统计上有缺陷，不能当精确阈值 [3]。实践里只用它的思想：每周加量别太猛（经验上 ≤ 10–20%，C） | B（批评） / C |
| 组织会被负荷「训练」 | 肌肉、肌腱、骨、软骨都在负荷下重建（机械转导）；完全休息会让能力继续下降，下次更容易疼 [4] | A（机制 + 多项试验） |
| 适应速度不同 | 肌肉几周就变强；肌腱、韧带、软骨要 **12 周以上**；所以肌腱问题「好得慢」是正常的 [4][5] | B |
| 全身因素也算负荷 | 睡眠少、压力大、能量吃得太少、刚生病，都会降低组织承受能力和提高疼痛敏感性 [6][7] | B |
| 预防最有效的是力量训练 | 力量训练让运动伤害减少约三分之一，单纯拉伸效果不明显 [8] | A |

**落到处方**：先找出「最近什么负荷变了」，把那一项降到能耐受的水平（不是全停），同时用渐进的力量训练把能力练上去，再一步步把原来的运动加回来。

## 2. 疼痛科学（讲给 Psir 听的版本）

| 要点 | 说明 | 等级 |
|---|---|---|
| 疼 ≠ 伤 | 疼是大脑判断「需要保护」时发出的警报，和组织损伤程度只是部分相关。没有疼痛的人做影像，也大量有「异常」（第 10 节）[9][10] | A |
| 警报会变敏感 | 疼久了（> 3 个月）神经系统会放大信号：轻碰也疼、范围扩散、和做了多少对不上。这时「疼一点」不代表在加重损伤 [9] | B |
| 练的时候有点疼可以 | 慢性肌肉骨骼疼痛里，允许练时轻中度疼痛的方案短期效果略好于「必须完全无痛」[11] | A（短期） |
| 怕动会让人更疼 | 因为怕疼而回避活动 → 去适应 → 更容易疼，形成循环；逐步暴露能打破它 [12] | B |
| 讲清楚本身就是治疗 | 疼痛教育配合运动，比单纯运动更能降低疼痛和恐惧 [13] | B |

**说话方式**（影响预后，C）：
- 说：「这是负荷超过了能力，可以练回来」「疼一点不等于伤得更重，我们看第二天早上的反应」「片子上的这些变化很多没疼的人也有」。
- 不说：「退化」「磨损」「错位」「骨头歪了」「椎间盘压神经了」「以后不能弯腰 / 不能跑了」「千万别动」。
- 也不说「肯定没事」：没检查不打包票，按红旗和灯来。

## 3. 疼痛监控模型（每日疼痛卡和 rehab-status 的依据）

Silbernagel 等在跟腱问题里证明：按疼痛规则继续运动，效果不比停练差 [14]。规则：
| 时间点 | 允许 | 超了怎么做 |
|---|---|---|
| 练 / 活动中 | ≤ 5/10（服务器把 ≤ 2 记绿，3–5 记黄） | > 5：这次的量太大，下次退一级 |
| 练完当晚 | 可以有点疼 | — |
| 第二天早上 | 回到平时水平 | 比平时更疼、更僵：退一级 |
| 一周趋势 | 不逐周上升 | 上升：退回上一阶段，查训练外负荷 |

**不同组织的阈值不同**（rehab-status 的灯是默认，部位文件更严格时按部位文件）：
| 组织 / 类型 | 练时允许 | 原因 | 等级 |
|---|---|---|---|
| 肌腱负荷型 | ≤ 5（黄灯可以继续） | 肌腱需要负荷才能重建，原研究就是这个阈值 [14] | B |
| 慢性非特异性疼痛（腰、颈、肩） | ≤ 3–5 | [11] | A |
| 关节内（半月板、软骨）、术后 | ≤ 3，且不能肿 | 肿是关节过载的信号（knee-meniscus.md） | C |
| 急性肌肉拉伤 | ≤ 4 可以（不必完全无痛） | 允许轻度疼痛的方案回场时间不比无痛方案慢 [15] | B |
| 神经相关型 | 远端症状不能加重 | 远端加重 = 神经更受刺激 | C |
| 骨的应力问题 | 冲击时不疼 | 骨要靠时间愈合，疼痛规则不适用；先转诊 | C |

## 4. 阶段与标准（以标准推进，不以天数推进）

| 阶段 | 目标 | 进入 | 关键内容 | 退出标准 | 等级 |
|---|---|---|---|---|---|
| 保护 | 让急性反应平息、不变差 | 急性伤 < 72 小时；复发期不动也疼 ≥ 4、夜里疼、明显肿 | 1–3 天减少诱发动作（不是卧床）；加压、抬高；无痛范围内活动；等长；能忍的有氧；练其他部位。软组织急性伤按 PEACE & LOVE：保护、抬高、加压、教育 → 负荷、乐观、有氧、运动 [16]；冰敷只当止痛，没有加快愈合的证据（C） | 不动时疼 ≤ 2；肿在消；日常活动疼 ≤ 3 | A–C |
| 加载 | 恢复对负荷的耐受、活动范围 | 保护期达标；慢性问题的起点 | 等长；低负荷慢速；活动度；走路 / 单车 | 连续约 7 天绿灯、第二天早上稳定；自重版 3 × 15 疼 ≤ 2 | B |
| 力量 | 把能力练到超过日常和运动需要 | 同上 | 渐进的重负荷（慢速）、单侧、功能动作；每周 2–3 次 | 患侧 ≥ 健侧 80–90%；部位功能测试疼 ≤ 2 | A–B |
| 回归 | 恢复速度、弹性、专项 | 同上 | 弹跳、变向、加减速、专项阶梯；不连着两天做高冲击 | 部位回场标准（第 8 节和部位文件第 6 节）全部达到 | B–C |
| 维持 | 不复发 | 回到运动 | 关键力量每周 1–2 次；热身含激活；复发预案 | 4 周无症状 → resolved | B |
- 慢性问题常从「加载」开始，不需要保护期。
- 复发（flare）不等于从头开始：退回一个阶段，通常 1–2 周就能回来（C）。

## 5. 剂量表（视频里该有的量，以及怎么换成 follow 的秒数）

| 目的 | 组 × 次 / 时长 | 节奏 | 强度 | 频率 | 依据 | 等级 |
|---|---|---|---|---|---|---|
| 等长止痛（肌腱） | 5 × 30–45 秒，组间 1–2 分钟 | 静止 | 中等到较大用力，疼 ≤ 3 | 每天 1–2 次，也可在运动前 | [17][18] | B（结果不一致） |
| 慢速重负荷（肌腱重建） | 3–4 组，15RM 逐周到 6RM | 3 秒上 + 3 秒下 | 最后 2 次吃力 | 每周 3 次，12 周 | [19][20] | B |
| 离心（跟腱经典方案） | 3 × 15，直腿和屈膝各一套 | 只做下放，3 秒 | 允许中度疼痛 | 每天 2 次，12 周 | [21] | B |
| 力量（肌肉 / 关节周围） | 2–4 × 8–15 | 2 秒上 + 2–3 秒下 | RIR 2–3（RPE 7–8） | 每周 2–3 次 | [22] | A |
| 肌耐力（肩袖、深层颈屈肌、核心） | 2–3 × 15–20 或 3–5 × 10 秒保持 | 慢 | RIR 2–3 | 每周 3 次到每天 | [22] | B |
| 弹性 / 弹跳 | 2–4 × 6–10 次 | 快、落地轻 | 先双脚后单脚，先原地后移动 | 每周 2–3 次，间隔 ≥ 48 小时 | [5] | C |
| 活动度 / 拉伸 | 每个 30–60 秒 × 2–3 | 慢 | 有拉伸感，疼 ≤ 3 | 每天 | — | C |
| 有氧（维持体能、止痛） | 20–40 分钟 | — | 能说完整句子 | 每周 3–5 次 | [6] | A |

**换成 follow 出片参数**（follow 的动作按秒数计，不按次数）：
- 等长：`secs` = 每组保持秒数（30–45），`rounds` = 组数；视频里每组之间要有休息。
- 慢速力量：每次约 6 秒（3 上 3 下），8–10 次 ≈ `secs` 50–60；12–15 次的低负荷版 ≈ `secs` 45–60（2 上 2 下）。
- 单侧动作 `sides: 2`（左右各一遍）；`--kind strength`；活动度和放松 `--kind stretch`。
- 整套时长控制在 5–15 分钟，能坚持比完美重要（habit-coach）。

## 6. 不同组织怎么加载

| 组织 | 喜欢 | 不喜欢（刺激期先避开） | 典型时间线 | 等级 |
|---|---|---|---|---|
| 肌腱 | 渐进的重而慢的负荷；先等长再动态，最后弹性 | 负荷突然增加的弹跳、冲刺、发球；**压迫**（跟腱附着处的勾脚拉伸、臀外侧肌腱的翘二郎腿、侧卧压痛侧）；完全休息 | 12 周起；早上僵、热身后好、第二天才知道练多了 [5][23] | B |
| 肌肉 | 尽早开始无痛到轻痛的负荷；离心和拉长位力量 | 伤后完全不动；过早冲刺 | 轻度 1–3 周，中度 3–8 周；伤后第 2 天开始负荷比第 9 天开始平均早回场约 3 周 [24] | B |
| 关节（软骨、半月板） | 周期性中等负荷（走路、单车、浅蹲）；周围肌群力量 | 负重深屈、踩地扭转、落地冲击；肿时加量 | 看肿：肿就减量 [25] | A–C |
| 韧带 | 早期保护下的活动 + 本体感觉 + 力量 | 长期固定 | 踝扭伤 2–6 周回运动，本体感觉练 3 个月以上防复发 [26] | A |
| 神经 | 让症状往中间收的姿势；神经滑动（不拉紧） | 持续牵拉神经的姿势；远端症状加重的动作 | 多数 6–12 周明显好转（C） | C |
| 骨 | 无痛的逐步冲击 | 带痛的冲击 | 应力损伤要医生管 | C |

## 7. 等长收缩止痛：证据如实说

- 一项小样本研究里，5 × 45 秒、约 70% 最大力的股四头肌等长，让髌腱疼痛即刻下降并维持约 45 分钟 [17]。
- 后来更大的交叉试验发现，等长和动态收缩的即时止痛差不多，且个体差异大 [18]。
- 结论（B，结果不一致）：等长是**加载期的好起点和比赛前的止痛工具**，不是神药；Psir 做了不缓解，就换成同等强度的慢速动态动作。

## 8. 回归运动的标准

| 维度 | 标准 | 等级 |
|---|---|---|
| 连续体 | 回到参与（练技术、不对抗）→ 回到运动（比赛但未必最佳）→ 回到最佳表现，每一步单独判断 [27] | C（共识） |
| 疼痛 | 整场专项强度时疼 ≤ 2，第二天早上不加重；没有肿 | C |
| 活动范围 | 和健侧基本一致 | C |
| 力量 | 患侧 ≥ 健侧 90%（肢体对称指数）；跳、单腿蹲等功能测试也看对称 | B–C |
| 专项阶梯 | 部位文件第 6 节的阶梯走完，每一步至少 2–3 次没问题 | C |
| 心理 | 不怕、不刻意护着；自己觉得准备好了 [27] | B |
| 风险权衡 | 结合比赛重要性、复发代价、Psir 的风险偏好一起定（StARRT）[28] | C |
| 医生 | 有结构性损伤、术后、医生交代过的，以医生同意为准 | — |

## 9. 去适应和「练没伤的地方」

- 固定或明显少动 1–2 周，肌肉量和力量就会明显下降，且身体对蛋白质的合成反应变差（B，见 `../../weight-nutrition/references/recovery-nutrition.md`）。
- 所以伤一处 ≠ 全停：没伤的部位照常练，有氧换成不刺激伤处的方式（膝伤骑车、肩伤走路或单车、踝伤游泳或单车）。
- 练健侧对患侧有少量力量保留作用（交叉迁移）[29]（B）。
- 停练 ≥ 1 周回来：从原来的约 70% 开始，两周回到原量（training-coach）。

## 10. 影像什么时候有用

| 情况 | 影像有没有用 | 等级 |
|---|---|---|
| 没有红旗的腰痛、颈痛 | 不需要常规拍片；拍了也不改善结果，反而增加焦虑和不必要的治疗 [30][31] | A |
| 疑似骨折（按 Ottawa 踝 / 膝规则、明显外伤） | 要拍 X 线 [32][33] | A |
| 红旗（马尾、进行性无力、肿瘤、感染、炎症型） | 要，由医生开 | A |
| 认真康复 6–12 周无改善、考虑打针或手术 | 由医生决定是否做核磁 | C |
| 片子上的「异常」 | 没疼的人里也很常见：腰椎间盘退变 20 岁约 37%、50 岁约 80%；椎间盘膨出 20 岁约 30%、50 岁约 60%[10]；无症状的人肩袖撕裂约三分之一，60 岁以上过半 [34] | A–B |
- Psir 拿着片子来：先说「这些变化很多没疼的人也有，关键看你的症状和功能」，再按分型和阶段走；医生的结论照抄进 `diagnosis`。

## 11. 被动治疗怎么看（Psir 问到时）

| 方法 | 结论 | 等级 |
|---|---|---|
| 热敷 | 急性 / 亚急性腰痛短期止痛有中等证据 [35]；其他部位当舒适手段 | B |
| 冰敷 | 急性期止痛可以，没有加快愈合的证据 [16] | C |
| 按摩、手法 | 短期缓解，配合运动才有长期意义 [30][36] | A–B |
| 拉伸 | 对防伤效果不明显 [8]；刺激期的肌腱不要拉（压迫）[23] | A |
| 护具、贴扎 | 踝扭伤后用护具优于固定，并能防复发 [26]；髌骨贴扎、肘部护带只有短期作用 [37] | A–B |
| 卧床 | 腰痛卧床比保持活动差 [38] | A |
| 腰围、牵引、超声、TENS | 腰痛不推荐 [30] | A |
| 药、封闭、PRP、手术 | 医生的决定；P-Health 不评价，只提醒「任何治疗都要配合负荷训练」 | — |

## 12. 大概多久能好（给 Psir 预期时用，C 级为主）

| 问题 | 一般时间线 |
|---|---|
| 急性非特异性腰痛 | 6 周内大多明显好转，之后改善变慢 [39]；一年内再犯很常见（lower-back.md 第 2 节） |
| 踝外侧扭伤（轻中度） | 2–6 周回运动；本体感觉练 3 个月以上 [26] |
| 肌肉拉伤 | 轻 1–3 周，中 3–8 周，拉长型（例如劈叉样受伤）更久 [15][24] |
| 肌腱负荷型 | 12 周起，有时 6 个月；第一个月多是「疼痛稳定」，力量是后面才上来的 [5][19] |
| 慢性肩痛（肩袖相关） | 训练 6–12 周开始明显改善 [40] |
- 跟 Psir 说预期时给范围和「怎么看在变好」（灯、疼痛趋势、能做的动作），不承诺日期。

# 肩

Psir 说肩疼、发球或高压疼、抬手够高处疼、侧睡压着疼、肩膀卡响时读这一页。流程在 `../SKILL.md`，通用原理在 `principles.md`，网球专项力量在 `../../training-coach/references/tennis.md`。
证据等级：A 指南 / 荟萃分析，B RCT / 队列，C 共识 / 经验。

 {"id":"motion","label":"活动有没有受限","type":"options","options":["能抬到头顶，中间一段疼","抬不高，别人帮也抬不上去","打球时突然没劲 / 发麻","没受限"]},
 {"id":"neck","label":"疼会不会","type":"multi","options":["窜过手肘到手","手指麻","转头低头时加重","都没有"]}]

- 「别人帮也抬不上去」→ 僵硬型；「突然没劲 / 发麻」→ 不稳型或神经；第四题选了前三项任意 → 先看 neck.md。
- 还要问：最近发球量、比赛频率、换拍 / 换线、力量课里有没有新加的推举或卧推；有没有摔过、肩膀脱出来过。

## 2. 分型和怎么区分

| 类型 | 典型表现 | 怎么区分 | 方向 | 等级 |
|---|---|---|---|---|
| 肩袖相关负荷型（最常见） | 肩外侧到上臂疼；抬手到中间一段（约 60–120°）疼，过了反而好；侧睡压着疼；发球、够高处重；慢慢出现、跟加量有关 | 自己能抬到头顶（只是疼），别人帮着也能到 → 活动范围没丢 | 渐进负荷训练是主线，6–12 周起效；手术减压不比假手术好 [1][2][3] | A |
| 僵硬型 | 慢慢变得哪个方向都抬不动，尤其外旋（小臂往外转）；夜里疼；多见 40–60 岁、有糖尿病或甲状腺问题 | 别人帮着也抬不上去（被动也受限） | 门诊（骨科 / 康复医学科）；在能忍范围内保持活动，不硬拉；时间长（以月计） | C |
| 不稳 / 松弛型 | 较年轻、关节偏松；发球举拍到后面（外展外旋）时突然发软、发麻（「死臂」）、怕往后；可能脱位过 | 「举拍到后面那一下会不会突然没劲？」 | 肩袖和肩胛的控制训练；脱位过 → 门诊骨科 | C |
| 肩锁关节型 | 肩顶端一个点疼；手臂横过胸前够对侧肩疼；卧推、双杠臂屈伸、俯卧撑下太深重；可能摔时肩着地 | 按肩顶那个小突起疼；横过胸前疼 | 避开横收和深推；摔伤后变形 → 尽快骨科 | C |
| 后侧紧（惯用侧内旋少） | 打球侧手往背后够、内旋明显比另一侧少；常伴肩袖相关负荷型 | 两侧对比「手背贴后腰往上够」，差一截 | 横向拉伸（手臂横过胸前）比「睡姿拉伸」更好接受 [4] | B–C |
| 颈部牵涉 | 疼窜过肘到手、手指麻；转头、低头、仰头会引出；肩本身活动不疼 | 动脖子会引出，动肩不会 | 按 neck.md | C |
| 内脏 / 心脏牵涉 | 左肩臂疼和用力有关、伴胸闷出汗；右肩尖疼在吃油腻后、伴右上腹疼 | 和肩的动作无关 | clinical-safety：前者急，后者尽快 | — |
| 急性外伤 | 摔时手撑地或肩着地；之后突然抬不起手（尤其 40 岁以上）；变形 | 有受伤那一下 + 突然没劲 | 尽快骨科（急性撕裂早评估更好，C） | C |

## 3. 红旗和转诊
| 情况 | 级别 | 去哪 |
|---|---|---|
| 左肩 / 左臂疼和用力有关，伴胸闷、出汗、气短 | 急 | 120 |
| 肩膀脱出来、变形，或摔后剧痛动不了 | 尽快（今天） | 急诊 / 骨科 |
| 外伤后突然抬不起手臂 | 尽快 | 骨科 / 运动医学科 |
| 肩或手臂进行性无力、手麻范围扩大 | 尽快 | 脊柱外科 / 神经科 |
| 肩红肿热伴发烧；有肿瘤史、夜里不动也疼、体重莫名下降 | 尽快 | 急诊 / 骨科 |
| 右肩尖疼伴右上腹疼、发烧或吃油腻后加重 | 尽快 | 急诊 / 普外科 |
| 被动活动也明显受限（僵硬型） | 门诊 | 骨科 / 康复医学科 |
| 认真练 12 周仍明显影响打球和睡觉 | 门诊 | 运动医学科 |
- 片子上的肩袖「撕裂」没疼的人也很常见（约三分之一，60 岁以上过半）[5]：先看症状和功能。

## 4. 动作红黄绿
| 灯 | 动作 | 说明 |
|---|---|---|
| 绿（加载期起） | 靠墙等长外旋 / 内旋 / 外展（中等用力）、钟摆、桌面滑手、侧卧外旋（轻）、弹力带划船、肩胛后下收、仰卧前锯肌推、低于疼痛高度的墙面滑手 | 疼 ≤ 3 |
| 黄（力量期起） | 弹力带 90/90 外旋、肩胛面上举（拇指朝上）先到 90° 再往上、俯卧 Y / T / W、俯卧撑加（顶端再推一下）、地雷架推、半跪单臂上推（轻）、对脸拉、高位下拉（拉到胸前） | 疼 ≤ 3–5 且第二天早上回到平时；一次只加一个变量 |
| 红（刺激期先不做） | 直立划船、颈后推举 / 颈后下拉、双杠臂屈伸、宽握大重量卧推、拇指朝下侧平举（「倒空罐」）、大重量过头推、借力引体；发球和高压的数量 / 力量照旧；硬做疼的「睡姿拉伸」 | 回归期按第 6 节逐步加回推举和发球 |
- 审视频常见的坑：「肩颈放松」里的颈后下拉、大幅度绕肩加负重；「肩部训练」里的直立划船和拇指朝下的侧平举。

## 5. 分阶段方案（肩袖相关负荷型为主，其他类型按第 2 节调整）
| 阶段 | 视频里该有的 | 量 | 频率 | 进下一阶段 |
|---|---|---|---|---|
| 保护 / 刺激期 | 等长外旋、外展；钟摆；肩胛后下收 | 等长 5 × 30–45 秒；其余每个 1–2 分钟 | 每天 1–2 次 | 夜里不再疼醒；日常抬手疼 ≤ 3 |
| 加载（2–4 周） | 侧卧外旋、弹力带划船、肩胛面上举到 90°、前锯肌推 | 3 × 12–15，RIR 2–3，慢放 3 秒 | 每天或隔天 | 7 天绿灯；上举到头顶疼 ≤ 2 |
| 力量（6–12 周） | 90/90 外旋、俯卧 Y / T、俯卧撑加、地雷架推、对脸拉、半跪上推；全身课保留下肢和核心 | 3 × 8–12，RIR 2 | 每周 3 次 | 第 6 节力量标准；过头动作疼 ≤ 2 |
| 回归 | 快速外旋（弹力带快速收、慢放）、小球抛接、发球阶梯 | 2–3 × 10–15 次快速 | 每周 2–3 次，隔天 | 第 6 节全部标准 |
| 维持 | 8 分钟肩肘预防（tennis.md）：外旋、Y-T、前臂离心、侧桥 | 2 × 15 | 每周 2 次 | — |
- 允许练时有轻度疼痛（≤ 3–5，第二天回到平时）：慢性肩痛里不必完全无痛 [6]（A）。
- 肩胛的控制（后下收、前锯肌）是基础 [7][8]（B–C）；但单练肩胛不够，肩袖的渐进负荷才是主线 [1]。
- 后侧紧：每天手臂横过胸前拉伸 3 × 30 秒 [4]（B–C）。

## 6. 回到网球（发球）
**标准**：
- 主动活动范围和健侧基本一样，惯用侧内旋不比另一侧少太多（手背贴后腰往上够只差一点）（C）。
- 外旋力量至少是内旋的三分之二左右（弹力带同一阻力，外旋能做的次数 / 力量接近内旋的 2/3–3/4）[9]（C）。
- 90/90 外旋 3 × 15、俯卧 Y 3 × 15、俯卧撑加 15 次都不疼。
- 发球阶梯走完，第二天早上不加重。
**阶梯**（每一步至少 2–3 次没问题再进，同一天不加两步；发球先隔天打）：
1. 底线对拉 20–30 分钟（不发球、不高压）。
2. 对拉 + 截击，加时长到平时的 75%。
3. 无球发球动作（影子发球）10–20 次。
4. 50% 力量发球 10–20 个 → 每次 +25% 数量或力量。
5. 75% → 100% 力量发球，总数回到平时。
6. 高压球、练习赛 → 正式比赛（一周比赛强度 ≤ 2–3 次）。
- 发球约一半的能量来自腿和躯干 [10]（C）：腿和核心弱、只靠胳膊甩，肩就要多扛。回归期同时练下肢和抗旋核心（tennis.md）。
- 换拍、加线磅、改握拍后肩疼：先换回原来的再看（C）。

## 7. 日常和睡觉
- 侧睡压痛侧会疼醒：睡另一侧、怀里抱个枕头托住上面那只手；仰睡时痛侧手臂下垫个薄枕（C）。
- 办公时手别长时间悬空够鼠标；够高处的东西放低一层（C）。
- 夜里不动也疼、和姿势无关 → 第 3 节红旗。

## 8. 请 Psir 找视频时怎么说
- 刺激期 / 加载期：「肩袖康复入门：弹力带外旋、靠墙等长、划船、肩胛后收，动作慢，一个人出镜，8 分钟左右，不要颈后下拉和直立划船。」
- 力量期：「网球肩部力量：90/90 外旋、俯卧 Y-T-W、俯卧撑加、对脸拉，一个人出镜，10–15 分钟。」
- 回归期：「网球发球前的肩部激活和快速外旋，带小球抛接，5–8 分钟。」

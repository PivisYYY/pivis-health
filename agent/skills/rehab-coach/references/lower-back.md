# 腰背

老大说腰疼、腰闪了、腰背紧、久坐腰酸、打球（尤其发球）后腰疼、腿后面窜麻时读这一页。流程在 `../SKILL.md`（先红旗 → 问诊 → 分型 → 阶段 → 疼痛卡），通用原理在 `principles.md`。
证据等级：A 指南 / 荟萃分析，B RCT / 队列，C 共识 / 经验。

---

- 「两条腿都有」→ 回 SKILL 第 1 步问鞍区和大小便。「疼或麻过了膝盖」→ 神经相关型。晨僵 > 30 分钟 → 看炎症型。
- 还要问：以前犯过几次、每次多久好；这次之前有没有加量（多打球、搬东西、久坐赶工、睡得少）。

## 2. 分型和怎么区分

| 类型 | 典型表现 | 怎么区分 | 方向 | 等级 |
|---|---|---|---|---|
| 非特异性 · 负荷型（约九成） | 腰和臀部疼，随姿势和活动变化；不过膝；没有红旗 | 换姿势、走一走会变；腿上没有过膝的症状 | 保持活动 + 渐进运动；6 周内多数明显好转 [1][2][3] | A |
| ├ 屈曲不耐受 | 久坐、弯腰、早上穿袜子重；站起来走走好 | 「坐久了重还是站久了重？」坐 → 这一类 | 先做伸展方向和中立位的动作；坐 30 分钟起来一次 | C |
| └ 伸展不耐受 | 站久、走久、后仰、发球、仰头够高处重；坐下或弯腰抱膝好 | 站 → 这一类 | 先做屈曲方向（抱膝、婴儿式）和抗伸展核心；发球量先减 | C |
| 神经根受刺激型 | 腿比腰疼，疼或麻过膝甚至到脚；咳嗽、打喷嚏、久坐加重 | 坐着伸直膝盖（像踢腿）会引出腿的疼麻；远端症状随姿势变 | 找让症状往腰中间收的姿势和动作；多数 6–12 周好转；无力加重转诊 [1] | A–C |
| 炎症型 | 40 岁前慢慢开始，超过 3 个月；晨僵 > 30 分钟；动了好、休息不好；后半夜疼醒、起床后好转；两边臀部交替疼 | 5 条里满足 4 条就要查 [4] | 风湿免疫科门诊；运动照常有益 | B |
| 牵涉型 | 侧腰疼伴尿频尿痛、发烧（肾）；突发撕裂样剧痛、年纪大、有心血管病（血管）；腹股沟疼、髋转不动（髋）| 动腰不加重；和排尿、进食、月经相关 | 按 clinical-safety 分级；髋 → hip-hamstring.md | C |
| 严重病理（红旗） | 见第 3 节 | — | 转诊 | A |
| 敏化 / 慢性型 | 超过 3 个月，反复；怕弯腰、护着腰；睡差、压力大时更重 | 「疼和做了多少对得上吗？」对不上、恐惧明显 | 疼痛教育 + 逐步暴露害怕的动作（认知功能疗法）+ 运动 + 睡眠和压力 [5][6] | A–B |

## 3. 红旗和转诊
| 情况 | 级别 | 去哪 |
|---|---|---|
| 鞍区麻木；新出现的排尿困难、尿失禁或大便失控；两腿疼麻无力 | 急 | 急诊（脊柱外科），今天 |
| 脚抬不起来、踮不起脚、无力越来越重 | 尽快 | 脊柱外科 / 骨科 |
| 有肿瘤史；不明原因体重下降；夜里不动也疼、躺平不缓解 | 尽快 | 骨科或内科 [7][8] |
| 摔伤后疼，或长期用激素、年纪大有骨质疏松的轻微外伤后疼 | 尽快 | 骨科拍片 [8] |
| 腰疼伴发烧、寒战；免疫力低 | 尽快 | 急诊或内科 |
| 突发撕裂样剧痛、腹部有搏动感、头晕 | 急 | 120 |
| 侧腰疼伴尿频尿痛、血尿或发烧 | 尽快 | 泌尿外科 / 急诊 |
| 第 2 节炎症型的表现 | 门诊 | 风湿免疫科 |
| 腿疼严重、6 周保守仍不能忍或影响生活 | 门诊 | 脊柱外科 / 疼痛科 |
| 认真练 6 周没改善 | 门诊 | 康复医学科 / 骨科 |
- 没有红旗不需要拍片 [1][9]；老大带着片子来，按 principles.md 第 10 节说。

## 4. 「腰闪了」的头 72 小时（保护期）
| 做 | 为什么 | 等级 |
|---|---|---|
| 保持活动：每小时起来走 5–10 分钟，能忍就照常上班 | 卧床比保持活动恢复慢 [10] | A |
| 热敷 15–20 分钟，一天几次 | 急性期短期止痛有中等证据 [11] | B |
| 舒服的姿势：侧躺两膝夹枕头；仰躺小腿搭在椅子上（髋膝 90°） | 减少腰部张力（C） | C |
| 小幅度动一动：仰卧抱膝左右轻摆、骨盆前后倾、小幅猫牛，每次 1–2 分钟 | 维持活动、减少保护性紧张（C） | C |
| 不用腰围、不卧床、不做强力拉伸和按压最疼的点 | [1] | A / C |
- 讲给老大：「腰闪了大多是组织被突然拉了一下，几天到两周会明显好；越早正常活动越快好。」
- 72 小时后疼得明显轻了就进加载期；腿上出现过膝的疼麻 → 重新分型。

## 5. 动作红黄绿
| 灯 | 动作 | 说明 |
|---|---|---|
| 绿（加载期起） | 骨盆前后倾、仰卧抱膝摆动、小幅猫牛、臀桥、鸟狗、死虫、屈膝侧桥、改良卷腹（一腿伸直、手垫腰下、只抬头肩）、走路、单车 | 屈曲不耐受的先少做抱膝和婴儿式；伸展不耐受的先少做俯卧撑起和大幅猫式下沉 |
| 黄（力量期起） | 木棍髋铰链 → 壶铃 / 哑铃硬拉、高脚杯深蹲、分腿蹲、单腿硬拉、农夫走、Pallof 推、伐木（轻）、背伸（小幅度） | 疼 ≤ 3 才加重；每次只加一个变量 |
| 红（刺激期 / 神经型先不做） | 负重弯腰加旋转（重的伐木、负重俄罗斯转体）、整个起身的仰卧起坐、仰卧双腿直腿一起抬、大重量硬拉到力竭、跳跃、大幅后仰（伸展不耐受时）；腿麻时的坐位体前屈、直腿拉伸 | 「先不做」不是「永远不能做」：力量期达标后逐步加回 |
- 弯腰本身不可怕：搬东西时腰弯不弯和以后腰痛没有明确关系 [12]（A）。关键是有能力、有准备，所以要练髋铰链，不是禁止弯腰。
- 审视频时常见的坑：「腰椎放松」视频里有大幅扭转压腿、双腿直腿抬、仰卧起坐；神经型时有直腿拉伸。

## 6. 分阶段方案
| 阶段 | 视频里该有的 | 量 | 频率 | 进下一阶段 |
|---|---|---|---|---|
| 保护（1–3 天） | 第 4 节的小幅动作 | 每次 5 分钟 | 每天 2–3 次 + 每小时走动 | 不动时疼 ≤ 2，能正常走 |
| 加载（1–3 周） | 骨盆倾斜、猫牛、臀桥、鸟狗、死虫、屈膝侧桥 | 每个 2 组：臀桥 12–15 次；鸟狗 / 侧桥 6–8 次 × 8–10 秒保持 | 每天 10–15 分钟；走路每天 20–30 分钟 | 7 天绿灯；日常（坐、弯腰穿袜子）疼 ≤ 2 |
| 力量（6–12 周） | 髋铰链 / 硬拉、高脚杯深蹲或分腿蹲、划船、农夫走、Pallof、侧桥（直腿） | 3 × 8–12，RIR 2–3；侧桥逐步到每边 45–60 秒 | 每周 2–3 次全身；走路每周 5 天 × 30 分钟 | 硬拉、深蹲、搬重物模式疼 ≤ 2；左右侧桥时间相差 < 10% [13] |
| 回归 | 转体发力（药球侧抛，如有）、单腿动作、敏捷；发球阶梯（第 8 节） | 2–3 × 6–10 次快速 | 每周 2 次 | 第 8 节标准 |
| 维持 | 力量课保留硬拉、侧桥、Pallof；走路 | — | 每周 2 次力量 + 每周 5 天走路 | — |
- 没有哪一种运动最好：普拉提、瑜伽、核心控制、一般力量效果差不多 [14][15]，**挑老大愿意坚持的**（A）。
- 慢性、怕动明显：逐步做他害怕的动作（先小幅度、少负荷），配合疼痛教育；认知功能疗法的大型试验效果明显且维持一年 [6]（B）。

## 7. 防复发（反复腰扭的人重点看）
| 做法 | 证据 | 等级 |
|---|---|---|
| 一年内再犯很常见（约三分之二的人会再犯一次）[16] | 所以「好了」之后要进维持期，不是停 | B |
| 运动（配合讲解）让再犯风险降低约 35–45% [17] | 力量 + 核心耐力，每周 2–3 次 | A |
| 走路计划（逐步到每周 5 次 × 30 分钟）把距离下一次复发的时间延长近一倍 [18] | 最便宜的防复发方法 | B |
| 腰围、鞋垫、单纯讲解不能防复发 [17] | 不推荐 | A |
| 放松 / 拉伸类视频 | 当下舒服、适合做热身或收尾；单独做防不了复发 | C |
- **已经有放松 / 拉伸类的腰背习惯**：复盘时建议在同一个项目里（同 id）加一节力量视频（髋铰链、侧桥、鸟狗、Pallof），放松视频保留做收尾；再加走路目标（步数，跟 training-coach 和 `pref.viz.steps` 一起看）。不另建项目。

## 8. 回到网球 / 运动
- 标准：日常疼 ≤ 2、晨僵 < 15 分钟；力量期标准达到；转体发力（药球或弹力带快速伐木）不疼；第二天早上不加重。
- 发球是腰最大的负荷（后仰 + 旋转 + 侧屈）：底线对拉 → 加跑动 → 发球 30–50% 力量 10–20 个 → 每次 +25% 数量或力量（隔一次加一次）→ 练习赛 → 比赛。发球那几步出现单侧后仰时腰疼，退回上一步。
- 发球时更多用腿蹬和髋转（principles 里「力从下往上传」），少靠腰硬折；技术问题建议找教练看（C）。

## 9. 日常
- 久坐：没有「唯一正确的坐姿」，关键是常换姿势；每 30–45 分钟起来动 1–2 分钟（C）[19]。
- 搬东西：靠近身体、先蹲一点、别突然发力加扭转；这些靠练髋铰链变成习惯，不靠怕。
- 睡觉：侧睡两膝夹枕头，仰睡膝下垫枕；床垫偏硬的中等硬度比很硬的好 [20]（B）。
- 疼的那几天睡不好会让疼更重（principles 第 1 节），睡前流程照常（cbti）。

## 10. 请老大找视频时怎么说
- 加载期：「腰背放松加核心激活，有臀桥、鸟狗、死虫、侧桥，动作慢，一个人出镜，10 分钟左右，不要仰卧起坐和大幅扭转。」
- 力量期：「髋铰链和硬拉入门、侧桥、Pallof 推、分腿蹲，哑铃或壶铃，一个人出镜，15–20 分钟。」
- 走路不需要视频：用打勾卡或步数目标。

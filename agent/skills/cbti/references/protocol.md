# CBT-I 协议细节

## 1. 每条规则和它的原理（重申规则时用一句）
| 规则 | 怎么算做到 | 原理（对 Psir 说的一句话） |
|---|---|---|
| 每天同一时间起床，周末也一样 | 比定好的时间晚不超过 15 分钟 | 起床时间是生物钟的锚。睡懒觉会让下一晚的困意变少，更难睡着。 |
| 最早上床时间之前不上床，困了才上床 | 上床不早于 `earliest_bed` | 先把在床上的时间压到和真实睡眠差不多，睡意攒够了，睡眠会变整、变深，之后再慢慢加回来。 |
| 醒着超过约 20 分钟就下床 | 估计着来，不看表；去暗光的地方做安静的事，困了再回床 | 床和「醒着着急」连在一起太久了，要重新让床只等于睡觉。 |
| 床只用来睡觉 | 不在床上刷手机、看剧、工作 | 同上：减少床上的清醒时间。 |
| 白天不睡，要睡就在 15:00 前、最多 20 分钟 | 午睡卡的时长和时间 | 白天睡会把晚上的睡意提前用掉。 |
| 咖啡因在最早上床前 8 小时截止 | 咖啡卡打勾 | 咖啡因的半衰期大约 5 小时，下午喝的到半夜还有一半在起作用。 |
| 睡前 1 小时放松，不看工作消息 | 睡前流程卡做完 | 先把兴奋水平降下来，躺下才容易睡着。 |
| 起床后尽快见光 10–30 分钟 | 不单独出卡，在日记的回复里提一句 | 早上的光帮生物钟定时，晚上会按时困。 |
| 酒精睡前 3 小时内不喝 | Psir 提到时提醒 | 酒让人容易睡着，但后半夜醒得更多。 |

## 2. 开始前的禁忌（发现就不做睡眠窗口限制，建议就医）
| 情况 | 为什么 | 对 Psir 说什么 |
|---|---|---|
| 双相情感障碍（或曾经几天不睡也不累、特别亢奋） | 限制睡眠可能诱发躁狂 | 「这种情况压缩睡眠有风险，先跟精神科医生确认再做。」 |
| 癫痫 | 缺觉会降低发作阈值 | 「缺觉可能诱发发作，先问神经科医生。」 |
| 打鼾很响、被人说憋气、夜里憋醒、白天很困 | 可能有睡眠呼吸问题，要先查 | 「这些情况建议先去睡眠门诊或呼吸科做个睡眠监测。」 |
| 倒班、常上夜班 | 固定起床时间做不到，方案要专门调 | 「倒班的方案要专门设计，建议找睡眠门诊。」 |
| 怀孕 | 不宜刻意缩短睡眠 | 「先跟产科医生说，只做放松和作息规律。」 |
| 开车或操作机器时犯困 | 限制初期白天会更困，有事故风险 | 「犯困期间别开车。先不缩窗口，去睡眠门诊看看。」 |
| 正在吃助眠药 | 换药、减药要医生决定 | 「药照医生说的吃，告诉医生你在做 CBT-I。」 |
| 情绪长期很低、有轻生念头 | 先处理安全 | 按 clinical-safety「情绪」处理 |

以上情况都只上：固定起床、床只用来睡、睡前放松、咖啡因截止。窗口不压缩。

## 3. 每周调窗口
数据：
- `./pivis-health sleep-week` → `efficiency_bands` 和每晚的 `efficiency_pct`（睡着的时间占在床时间的比例，由 WHOOP 算）。
- 不算平均。把每晚分到三档：≥90%、85–89%、<85%，再加一栏「无数据」。

| 条件（按顺序判断，命中就停） | 决定 |
|---|---|
| 有数据的晚少于 5 晚 | 不变。对 Psir 说「这周有 N 晚没有数据，先不调」 |
| Psir 说开车或工作时犯困 | +15 分钟（安全优先），并按 clinical-safety 提醒 |
| 日记里入睡要「30–60」或「1 小时+」的晚 ≥3 晚 | 不加。设备可能高估了，先把下床这条做到 |
| 有数据的晚里超过一半 ≥90% | +15 分钟：最早上床提前 15 分钟 |
| 有数据的晚里超过一半 <85% | −15 分钟：最早上床推后 15 分钟（窗口不少于 5.5 小时，已经到 5.5 就不变） |
| 其他 | 不变 |

「超过一半」等于看这 7 晚的中位数：≥90% 加，<85% 减，中间不变。

调整后，下面三个时间跟着一起挪：咖啡截止 = 最早上床 − 8 小时；睡前流程 = 最早上床 − 60 分钟；日记时间不变。

依从性不够时（日记少于 5/7，或下床、上床规则破了 3 次以上）：窗口不变。复盘先谈执行，按 habit-coach 找障碍。不靠调窗口解决执行问题。

## 4. 疗程
- 第 1 周：定窗口，开始全部规则。头 1–2 周白天会更困，这是正常反应。提前告诉 Psir，并提醒困的时候别开车。
- 第 2–6 周：每周复盘调一次。
- 结束：连续两周窗口没有变，并且 Psir 说白天精神好，就转入维持。项目 6 周到期，复盘时问要不要延长 2 周（project-set 改 days）。
- 6–8 周认真执行（日记 ≥5/7）还是没有改善：建议去睡眠门诊。

## 5. 复发预案（结束时写进 learn.sleep，方便以后用）
- 偶尔一两晚差：不补觉，不提前上床，照常起床。
- 出差、倒时差、生病：起床时间尽量守；其他规则可以暂停，回来就恢复，记进 `sleep.cbti.history`。
- 结束后又连续两周、每周 3 晚以上睡不好：重开日记和刺激控制；必要时按第 3 节重新算窗口。

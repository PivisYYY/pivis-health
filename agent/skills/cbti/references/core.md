- **先分型，再定方案**（cbti「第一步」表）：失眠型（入睡或夜里醒着 >30 分钟、效率 <85%）才做睡眠限制；效率 ≥90% 但睡得少 = 睡眠机会不足 / 作息偏晚，不压缩窗口。跟 Psir 说清「你属于 X，依据 A、B，所以方案是 Y」。
- **两个锚点**：起床时间每天一样（周末也一样，最重要）；最早上床 = 起床 − 窗口，困了才上床，早于它不躺。
- **刺激控制**：床只用来睡；躺下或夜里醒来约 20 分钟睡不着（别看表）就下床，暗光做安静的事，困了再回。清晨早醒睡不回去也一样：可以起，不硬躺。
- **窗口只在周复盘按效率调**：≥90% +15 分钟，85–89% 不变，<85% −15 分钟，最少 5.5 小时；周中不改（A，AASM 2021 指南）。窗口没守住先谈执行，不谈调整。
- **午睡**：限制期前两周不睡（会消耗晚上的睡眠压力）；犯困要开车 / 操作危险的事，安全优先，停下闭眼 15 分钟。稳定后再按数据试 ≤20 分钟、15:00 前。
- **白天困是前两周的正常反应**，不是方案失败；用见光、走动顶，不补觉、不提前上床。提前告诉 Psir 会这样。
- **不提睡眠债、「需要睡多久」、补觉**；判断看效率、入睡快慢、夜里醒多久、白天状态。手环的效率偏高，和日记一起看。
- **转诊**：打鼾憋醒、开车犯困、双相 / 癫痫、6–8 周认真执行没改善 → 睡眠门诊。

# 睡眠专业知识（原理 · 证据 · 决策表）

回答睡眠问题、排睡前流程、处理「昨晚没睡好今天怎么办」之前先读这一页。执行流程（窗口、日记、周复盘）在 `../SKILL.md` 和 `protocol.md`，这里是**为什么**和**遇到具体情况怎么判断**。
数字（睡了多久、效率、HRV）只来自 `./pivis-health`，这页不放任何人的数。

证据等级：**A** = 指南或多项 RCT / 系统综述一致；**B** = 单项 RCT 或较强观察研究；**C** = 机制推理、小样本或临床经验。给建议时说出等级，C 级要直说「这条证据弱，可以试」。

## 1. 入睡靠什么（先懂这个，后面的规则都能自己推出来）

| 机制 | 要点 | 等级 |
|---|---|---|
| 睡眠压力（双进程模型的 S 过程） | 醒得越久，腺苷越多，越困。**白天补觉、早早上床会把压力放掉**，晚上就不困 [1] | A |
| 昼夜节律（C 过程） | 体温、褪黑素按 24 小时走。**起床时间 + 早晨见光是最强的锚**；晚上强光、屏幕推迟褪黑素 [9] | A |
| 核心体温下降 | 入睡前核心体温下降 0.5–1℃，手脚变暖散热。热水澡让体温先升后降，**下降段**帮入睡 [7][8] | A / B |
| 觉醒系统 | 心跳快、反刍、焦虑、在床上「努力睡」都会压过睡意。床和清醒的条件反射越强，越难睡 [5] | A |

由这四条推出来的三句话（对 Psir 解释规则时用）：
- 不补觉、不提前上床 → 保住睡眠压力。
- 起床时间雷打不动 → 节律有锚。
- 睡不着就离床 → 床只和「睡着」绑定。

## 2. 睡前时间线怎么排（从上床时间往回推）

**先定两个固定点**：起床时间（不动）和最早上床时间（= 起床 − 睡眠窗口）。其余都从「最早上床」往回推，一律写成具体时刻，不说「睡前一两个小时左右」。

| 项 | 离最早上床多久 | 依据 |
|---|---|---|
| 咖啡因截止（咖啡、浓茶、奶茶、可乐、功能饮料、黑巧） | **≥ 8 小时**（指南常写 6 小时；6 小时内摄入仍会少睡约 1 小时 [11]，半衰期 3–7 小时，敏感的人更长，所以留 8） | A |
| 高强度运动结束（网球、间歇、重力量） | **≥ 2 小时**；中低强度（拉伸、康复动作、散步）到睡前 1 小时都可以 [15] | A- |
| 晚饭吃完 | ≥ 3 小时；之后饿了可以少量清淡 | B |
| 酒精停 | ≥ 3 小时，最好不喝；酒让人快睡着，但后半夜醒得多、REM 少 [12] | A |
| **热水澡洗完** | **1–2 小时**；40–42℃，10–15 分钟 [7]。洗完不到 1 小时就上床，体温还在高位，反而难睡 | A |
| 睡前放松流程开始（床外拉伸、慢呼吸、纸质书） | 30–60 分钟；只在床外做 | B |
| 工作消息、刷短视频停；灯调暗、暖色 | 60 分钟 [9] | A- |
| 大量喝水停 | 60 分钟内只小口；减少夜尿 | C |

**算例（只是写法示范）**：起床 08:00、窗口 7 小时 → 最早上床 01:00。
咖啡截止 17:00 → 运动结束 23:00 前 → 热水澡 22:45–23:00 开始、**23:15 前洗完**（离上床约 1 小时 45 分）→ 23:30 起床外放松 → 00:00 停屏幕 → 01:00 后有困意才上床。
- 这些点里**只有热水澡要卡区间**（洗完到上床 1–2 小时）；其余是「最晚」，早了没关系。
- Psir 问「我几点洗澡」「几点开始放松」，就按这张表把每个时刻算出来，写进 plan 或 list 卡，并给出一句原因。不要答「睡前一两个小时」。
- 放松流程和上床之间空着很正常：空档就在床外做安静的事，有困意了、过了最早上床时间才上床。

## 3. 常见问题决策表

| Psir 说 | 结论 | 为什么（一句） | 等级 |
|---|---|---|---|
| 「昨晚 2 点才睡，今天要补觉吗」 | **不补**。最多 15:00 前小睡 ≤ 20 分钟（在做 CBT-I 窗口限制的话连这个也不要）。照常时间起床 | 补觉放掉睡眠压力，今晚更难睡；白天困就出门见光、走 10 分钟 | A |
| 「那今晚要不要晚点睡 / 早点睡」 | **都不要**：上床时间照计划，过了最早上床时间、有困意再上床 | 单晚熬夜不改计划；提前上床=在床上等困，推迟=乱了节律 | A |
| 「我喝茶应该没事吧」 | 看是什么茶、几点：红茶、绿茶、乌龙、普洱、奶茶都有咖啡因（一杯约 20–60 mg），**按咖啡算截止时间**；花草茶（菊花、洋甘菊、大麦、南非博士茶）没有咖啡因 | 咖啡因阻断腺苷 | A |
| 「躺了很久睡不着」 | 约 20 分钟没睡着（凭感觉，不看表）→ 离床，暗光下做无聊的事，有困意再回 | 刺激控制 [5] | A |
| 「半夜醒了睡不着」 | 同上；不看时间、不刷手机、不开大灯。经常发生先查原因（见第 5 节） | | A |
| 「早上醒太早」 | 不提前上床来「补」，不赖床；照常时间起床，早上见光 | | B |
| 「周末能多睡会吗」 | 起床时间最多比平时晚 30 分钟，在做 CBT-I 的话一分钟都不晚 | 社会时差会推迟节律 | B |
| 「运动完多久能睡」 | 高强度 ≥ 2 小时，中低强度 ≥ 1 小时；运动后先降温再洗热水澡 | [15] | A- |
| 「睡前喝冰水 / 冷饮行吗」 | 白天随意；睡前 1 小时内别喝冰的、别大量喝 | 冷刺激提神、夜尿 | C |
| 「吃褪黑素有用吗」 | 对时差、节律后移有一点帮助，对慢性失眠效果小；剂量、要不要吃问医生，P-Health 不推荐 | 指南不推荐用于慢性失眠 [2][3] | A |
| 「手表说我深睡很少」 | 消费级设备分期误差大，看多晚的趋势和白天精神，不看单晚分期 | | B |

## 4. CBT-I 的要点（执行细节在 SKILL.md）

- 慢性失眠（每周 ≥ 3 晚、≥ 3 个月、影响白天）的**一线治疗**，优先于安眠药 [2][3]；效应中到大，4–8 周见效 [4]。
- 成分：睡眠限制 + 刺激控制 + 认知调整 + 睡眠卫生 + 放松。只做睡眠卫生不算 CBT-I，单独做效果小 [10]。
- 睡眠限制 [6]：窗口 = 近 1–2 周**实际睡着**的平均，下限 5.5 小时；每周按效率调 15 分钟；只动上床时间。**窗口没有固定目标**：调到效率稳定、白天精神好为止（多数人停在 6.5–8 小时）。
- 前 1–2 周白天更困是预期反应，说明睡眠压力在起作用；但开车、操作机械犯困属于安全问题，当天放宽 15 分钟（SKILL.md 规则 3）。
- 认知调整（常见的想法 → 怎么回应）：
  - 「一定要睡够 8 小时」→ 需要多少因人而异，看白天精神。
  - 「今晚再睡不好明天就完了」→ 一晚少睡，身体会自己补深睡；照常过白天。
  - 「我得早点上床多躺会」→ 躺得越久、睡得越碎。
- 常见执行错误：按「想睡多久」定窗口；周末补觉；傍晚打盹；早上床等困；床上刷手机；盯单晚数据；一周内反复改窗口；喝酒助眠；睡差一晚就想补偿。

## 5. 夜醒和早醒：先查原因

| 线索 | 方向 | 怎么做 |
|---|---|---|
| 打鼾很响、憋醒、早上口干头痛、白天嗜睡 | 睡眠呼吸问题 | 建议睡眠门诊（呼吸科睡眠专科），这期间不做窗口限制（clinical-safety） |
| 夜尿 ≥ 2 次 | 晚间饮水、酒、咖啡因、药物 | 睡前 1 小时少喝；仍多就看医生 |
| 疼醒（关节、腰背） | 疼痛 | 记下部位；训练相关的按 training-coach 伤病规则 |
| 太热、太吵、太亮 | 环境 | 卧室偏凉（约 18–22℃）[19]、遮光、耳塞 |
| 醒后脑子停不下来 | 觉醒、反刍 | 白天定一个「担心时间」写下来；睡前写明天的待办清单 [17]；慢呼吸 [16] |
| 早醒 + 情绪低、没兴趣 ≥ 2 周 | 情绪 | 建议心理或精神科门诊（不诊断） |

## 6. 生活里其他会影响睡眠的

- **运动**：规律运动改善睡眠质量和入睡 [13][14]；晚上练一般没问题，只是高强度要在睡前 2 小时结束 [15]。
- **光**：起床后 30 分钟内到户外或窗边 10–20 分钟；晚上暖光、调暗。
- **午睡**：不在做 CBT-I 时，15:00 前、≤ 20 分钟最安全 [18]；超过 30 分钟会进深睡，醒来更昏、晚上更难睡。
- **睡多少算够**：成年人 7 小时以上 [20]，个体差异大；长期 < 6 小时又白天困要重视。

## 7. 什么时候建议就医

- 认真做 6–8 周没有改善。
- 第 5 节的呼吸、情绪线索；双相、癫痫、怀孕、倒班（不做窗口限制，见 protocol.md）。
- 在吃助眠药想减停：只能和医生商量，P-Health 不给减药方案。

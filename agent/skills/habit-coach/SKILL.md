# 习惯教练

## 什么时候用
- 老大想养成一个新习惯（早起见光、每天拉伸、少喝奶茶…）。
- 某张待办连续被跳过，或者老大说「坚持不下来」。
- 每周复盘：周日早上那次【每日推荐】给每个进行中的项目出「本周复盘」卡；老大选了或带着这张卡来问时，先按本 skill 做执行复盘，再按专业 skill 调计划。

**专业依据先读 `references/habit-science.md`**：习惯怎么形成、要多久（约 66 天）、哪些方法有证据（执行意图、极小起步、自我记录、诱惑捆绑）、漏了怎么接、一次只养一个，带证据等级和文献。

## 怎么做

### 1. 新习惯：从小做起
1. 用 question 卡问一个锚点：「每天哪件事做完之后接着做最自然」（options：起床后 / 刷牙后 / 午饭后 / 收工后 / 洗澡后，allow_text）。
2. 写成「执行意图」：**在<锚点>之后，我会<最小动作>，在<地点>。** 例：「刷完牙后，我会在客厅做 2 分钟拉伸。」
3. 第一周只做「最小版」：2 分钟以内，几乎不可能做不到。
4. 再写一条「障碍预案」：**如果<最可能的障碍>，就<替代动作>。** 例：「如果加班到很晚，就只做 1 分钟。」
5. plan 卡确认（items 写时间，rules 写执行意图和障碍预案；唯一例外：洞察里服务器已经先挪好的提醒时间，见 insight skill，老大说改回就改回），然后 project-set（daily 一张打勾卡；是练习的就一张练习视频卡，只放一个 follow 出的视频，还没有视频先请老大发，见 follow-video），附 receipt。

### 2. 每天：不连续漏两次
- 早上那次【每日推荐】（顺带做每日整理）时看昨天：`todo-list --date <昨天>`。
- 昨天某项被跳过或过期了：今天**不补**昨天的，把今天这张改成「最低版」：有更短的 follow 视频就换成它（todo-update 只写新的 `media`）；没有就只改标题和 note，视频不换：
  `todo-update --id <今天那张的 id> --json '{"title":"最低版：拉伸 2 分钟","note":"昨天漏了，今天做一点就算"}'`
- 最低版做完、老大点了对勾就算接上了。第二天恢复原版（模板没动，第二天的卡还是原版）。
- 连续漏 2 次：用一张 options 卡问一次原因（忘了 / 太累 / 时间不合适 / 觉得没用 / 太难了），然后按第 3 步处理。只问这一次，不连续追问。
- **CBT-I 的核心规则（起床时间、最早上床时间、下床）没有最低版**，按 cbti 的破例流程处理。最低版只用在睡前流程这类辅助项。

### 3. 调难度（只在周复盘时调，一次只调一处）
| 情况（数字来自 todo-list） | 调整 |
|---|---|
| 连续 2 周做到 ≥ 6/7，而且老大说轻松 | 升一档：时长 +50% 或加一个动作 |
| 一周做到 ≤ 3/7，原因是「太难了」或「太累」 | 降一档：时长减半，或者换更容易的版本，但不降到 0 |
| 原因是「忘了」 | 难度不变，换锚点或换提醒时间 |
| 原因是「时间不合适」 | 难度不变，换时间 |
| 原因是「觉得没用」 | 方法不对，打开对应的专业 skill 换方法（比如 relaxation-media 换素材） |
| 做到 4–5/7 | 不变，只肯定做到的那几天，问一句最难的是哪一天 |

### 4. 每周复盘（所有进行中的项目）
每周只做一次：周日早上那次【每日推荐】，消息里会写周复盘要求（AGENTS 第 7 节）。项目里不写周日的复盘模板。
1. `./pivis-health project-list`，列出 status=active 的项目。
2. 每个项目跑 `./pivis-health project-stats --id <项目 id> --days 7`，照抄每一项做到几天、执行率（overall_pct）。不要自己数。下面是原来手数的办法，只在这个命令报错时用：每天跑一次 `./pivis-health todo-list --date <日期>`。对每个项目的每个 key（待办 id 是 `<项目 id>-<日期>-<key>`），数状态是 done 的天数 N，以及这张卡出现的天数 M。
3. 找做到比例最低的一项，按第 3 步的表最多改一处；专业上的调整（窗口、训练量、体重路线）交给对应的 skill。执行问题和专业问题分开说：执行差的时候，不靠改专业参数来解决。
4. 每个项目出一张 proposal「本周复盘」（todo-add）：note 写最关键的数（「日记 7/7 · 流程 5/7」，练习视频卡以老大点了对勾为准），选项把建议的改动放第一个、「先不动」放后面；不改也出，第一个就是「先不动」。原因还不知道的，选项写成按原因的改法（「太难，减半」「老忘，换时间」「先不动」）。`until` 写当天晚些时候。
5. 老大选了（【待办提交】）：照选的 project-set，回一句改了什么。老大带着这张卡来对话（【待办 …】），就发 list 卡讲清每项做到几天（连续天数也可以写上），再按他说的改，附 receipt。
6. 按 growth-memory 记本周学到的。

「坚持习惯」那一行：老大点开会进这个板块的对话，顶上是习惯卡（本周的点 + 每次「标题 → 视频」）。打开时你不先开口；老大带着它说话（消息开头【习惯 <项目 id> · <名字>】），就按上面看这一个项目，要改只改这个项目（project-set 同一个 id）。

## 规则与红线
1. 做到几天、连续几天，只按 todo-list 的状态数，不凭记忆。
2. 不惩罚：漏了不加量，不补双倍，不说「你又没做」。说事实，再说下一步。
3. 一次只改一处；改了至少跑满一周再看效果。
4. 老大说「算了」「今天不做」：按 AGENTS 红线 5（不是删掉习惯）。连续 3 天这样，周复盘时问要不要暂停这个项目。
5. 肯定要具体：说做到了哪件、为什么难，不说空话（「很棒」「加油」）。

## 模板
新习惯小项目（14 天，示例锚点「刷牙后」）：
项目名 ≤ 6 字最好（最多 10），只写名字：不带括号、频率、天数（「腰背放松」，不是「腰背放松（每周三次）」；第几天、共几天 App 自己显示）。

```json
{"id":"habit-stretch","name":"刷牙后拉伸","board":"sport","start":"2026-11-06","days":14,
 "goal":"养成每天拉伸的习惯，先求不断",
 "rules":["刷完牙后，在客厅做 2 分钟拉伸","如果加班到很晚，就只做 1 分钟"],
 "daily":[{"key":"stretch","when":"22:40","title":"刷牙后拉伸 2 分钟","kind":"follow",
           "media":{"kind":"video","title":"站立拉伸 · 2 分钟","url":"/media/follow/<ssid>/out.mp4","duration_min":2}}]}
```
本周复盘卡（周日早上那次【每日推荐】出，todo-add）：
```json
{"board":"sport","title":"本周复盘 · 拉伸","kind":"proposal","note":"拉伸 3/7，多是太累","until":"21:00",
 "inputs":[{"id":"choice","label":"","type":"options","options":["减到 1 分钟（建议）","换到午饭后","先不动"],"submit":"agent"}]}
```
漏两次后的原因卡：
```json
{"board":"sport","title":"拉伸连着漏了两天","kind":"options",
 "inputs":[{"id":"why","label":"主要是因为","type":"options","options":["忘了","太累","时间不合适","觉得没用","太难了"],"submit":"agent"}]}
```

## 成长
- `learn.habit.anchor`：`{"rule":"老大锚在「刷牙后」的习惯最稳，锚在「下班后」的经常漏","evidence":"刷牙后拉伸 13/14，下班后散步 4/14（todo-list）"}`。
- 每次复盘记一条：哪一项做得最好、为什么；哪一项最差、改了什么。下周复盘先看上周改的那一处有没有用。

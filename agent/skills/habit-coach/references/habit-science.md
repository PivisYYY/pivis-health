# 习惯养成的专业依据

老大说「坚持不下来」「想养成…」「漏了好几天」「想同时改好几样」，或者周复盘要调难度之前先读这一页。执行流程（锚点、最小版、不连续漏两次、调难度）在 `../SKILL.md`。
做到几天只按 `todo-list` / `project-stats` 数。

证据等级：**A** 多 RCT / 系统综述一致；**B** 单项研究；**C** 经验或机制。

---

## 1. 习惯是怎么形成的

| 要点 | 说明 | 等级 |
|---|---|---|
| 习惯 = 情境触发的自动行为 | 在同一个情境（时间、地点、前一件事）反复做，久了不用想就会做 [3] | A |
| 要多久 | 中位数约 **66 天**，因人因事 18–254 天不等；简单的（喝水）快，复杂的（运动）慢 [1] | B |
| 漏一天不影响 | **偶尔漏一次对习惯形成几乎没有影响** [1]；真正危险的是连漏、和「反正已经破了」的放弃心理 | B |
| 动机会退，情境不会 | 靠意志力的行为在累、忙的时候最先掉；固定锚点比「有空就做」可靠得多 [3] | A |

对老大说的版本：「一般要两个月左右才变自动；漏一天没关系，别连漏两天。」

## 2. 哪些方法有证据（按效果和成本）

| 方法 | 做法 | 依据 | 等级 |
|---|---|---|---|
| 执行意图 | 「在<锚点>之后，我会<动作>，在<地点>」；加「如果<障碍>，就<替代>」 | 对目标达成有中到大效果（d ≈ 0.65）[2] | A |
| 极小起步 | 第一周 2 分钟以内的版本，先把「做」这件事和锚点绑上，再加量 | 降低启动阻力，减少早期放弃 | B / C |
| 自我记录 | 每次做完打勾、看到连续天数 | 监测进度本身就能促进达成，公开或记录下来效果更好 [4] | A |
| 诱惑捆绑 | 把想做的事（听播客、追剧）只在做习惯时做 | 健身房到场率明显提高 [5] | B |
| 新起点 | 下周一、月初、生日、假期后是开始新习惯的好时机，人更有动力 | [6] | B |
| 具体目标 | 「每周 3 次 20 分钟」比「多运动」好 | [7] | A |
| 环境设计 | 把要做的东西放在眼前（垫子铺好、水杯放桌上），把要少做的藏起来、加步骤 | 减少决策、利用情境 | B |

**一次只养一个新习惯**：同时改好几样，注意力和意志力分散，一般都失败。前一个做到 ≥ 5/7 天、稳了两周，再加下一个。

## 3. 漏了、断了怎么办

- **「破戒效应」**：漏一次后觉得「反正已经破了」于是全放弃，是最常见的失败路径。应对：把漏看成数据，不看成失败；不补、不罚，今天做最低版接上（SKILL.md 第 2 步）[8]。
- 对自己宽容（不自责）的人，失败后更容易重新开始（B）。所以 P-Health 不说「你又没做」，说事实和下一步。
- 漏了一周以上：不从原来的量接，回到最小版重新开始一周，再升回去。

## 4. 常见问题决策表

| 老大说 | 结论 | 为什么 | 等级 |
|---|---|---|---|
| 「坚持不下来」 | 先问哪里卡（忘了 / 累 / 时间不对 / 太难 / 没用），按 SKILL.md 第 3 步只改一处；多半是锚点不对或太难 | [2][3] | A |
| 「漏了 3 天，是不是白练了」 | 没有白练，偶尔漏对形成习惯影响很小；今天做最低版接上 | [1] | B |
| 「我想同时改作息、饮食、运动」 | 一次一个；先挑影响最大、最容易做的那个（往往是固定起床时间） | 第 2 节 | B |
| 「要不要奖励自己」 | 可以，用诱惑捆绑或做完立刻的小奖励；别用吃的奖励减重习惯 | [5] | B |
| 「多久能变成习惯」 | 两个月左右，简单的快、复杂的慢；看「不用想就做了」的感觉 | [1] | B |
| 「要不要打卡发朋友圈」 | 记录有用；公开可以加一点约束，但别让它变成压力 | [4] | A- |
| 「太忙了，没时间」 | 降到最小版（2 分钟）而不是停；换到更固定的锚点 | 第 1 节 | B |

## 5. 什么时候不是习惯问题

- 一直做不到、伴随明显疲劳、情绪低落、睡眠很差：先看身体和情绪（stress-recovery、cbti、clinical-safety），不是意志力问题。
- 对某件事反复做不到是因为疼（训练）或不舒服（饮食用药反应）：交给对应的专业 skill 调整方法。

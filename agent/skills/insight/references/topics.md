# 对话主题标签（每周一次，后台会话）

服务器每周把 Psir 上周在四个对话里说的话（只取 Psir 说的，不取 P-Health 的）交给后台会话，要一个 JSON：

```json
{"items":[{"date":"2026-11-03","kind":"body","label":"肩膀"},{"date":"2026-11-04","kind":"concern","label":"睡不着"}]}
```

- `kind`：`body` 身体部位（肩膀、膝盖、腰）；`concern` 困扰（睡不着、累、压力大）；`mention` 提到的事（打网球、出差、喝酒）。
- `label` 不超过 8 个字；同一天同一个标签只写一次；不写人名、地名、别人的事。
- 结果存 `chat_topics.jsonl`（只在家里的服务器上），二期用来找「反复提到却没有计划在管」的事。

# 找素材：搜索词、标准、核对

## 1. 默认时长（老大没说时用）
| 用途 | 类型 | 时长 |
|---|---|---|
| 睡前（床外做） | 拉伸视频 | 8–15 分钟 |
| 睡前（坐着或躺下前） | 呼吸引导、身体扫描 | 6–15 分钟 |
| 入睡背景 | 白噪音、自然声 | ≥ 60 分钟，或者能循环 |
| 午间 | 呼吸、短冥想 | 5–10 分钟 |
| 压力大时 | 呼吸（叹息式、箱式） | 3–6 分钟 |
| 运动后 | 拉伸视频 | 8–12 分钟 |

## 2. 搜索词（先用前两个，不够再换）
练习类（呼吸、身体扫描、拉伸、正念）找的是能交给 follow 出片的视频：一个人出镜、全身入镜、镜头不乱切。B 站搜不到，可以把同样的词放到小红书搜。白噪音、自然声、轻音乐只在对话里发音频卡，不出片。
| 类型 | 搜索词 |
|---|---|
| 呼吸引导 | `B站 4-7-8 呼吸 跟练 中文`、`B站 呼吸引导 放松 5分钟`、`B站 箱式呼吸 跟练`、`B站 生理性叹息 呼吸` |
| 身体扫描 | `B站 身体扫描 冥想 引导 中文`、`B站 正念 身体扫描 15分钟`、`B站 睡前 身体扫描 女声` |
| 白噪音、自然声 | `B站 雨声 白噪音 1小时 无广告`、`B站 粉红噪音 睡眠`、`B站 海浪声 助眠 循环` |
| 拉伸视频 | `B站 睡前拉伸 跟练 10分钟 温和`、`B站 站立拉伸 全身 跟练`、`B站 办公室 肩颈拉伸 跟练`、`B站 网球 赛后 拉伸` |
| 正念冥想 | `B站 正念冥想 引导 10分钟 中文`、`B站 三分钟呼吸空间 正念` |
| 轻音乐 | `B站 睡前 纯音乐 无人声 1小时` |

## 3. 筛选（每条都要满足）
1. **公开**：不用登录就能播；不是大会员专享、充电专属或付费课程的试看片段。
2. **单集**：单个视频，或者多 P 合集的第 1 P（只认 BV 号，用的都是第 1 P）。
3. **中文**：普通话引导，语速平稳；白噪音和纯音乐不需要人声。
4. **干净**：开头没有长广告或口播带货，中途不插推广，不引导加群、加微信。
5. **可信**：播放量 ≥ 1 万，或者来自医院、高校、心理机构、认证的 UP 主。评论区没有一片差评。
6. **不夸大**：标题和简介里没有「治愈」「根治」「7 天告别失眠」这类说法。
7. **时长**对得上第 1 节，或者老大说的时长。
8. **拉伸**：动作温和，站着或坐着就能做，不要器械，不倒立；不包含老大有伤部位的负重动作。

## 4. 核对（打开页面看）
- 标题、UP 主、时长、播放量：照页面上写的抄，不要估。
- BV 号：从链接里取 `BV` 加后面 10 位。链接写成 `https://www.bilibili.com/video/BV…`。
- 打不开、要登录、或者看不到时长的：丢掉，换下一个。
- 搜了两轮还凑不到 2 个合格的：如实告诉老大「这类素材没找到合格的」，请他发一个看过、觉得好的博主视频，用 follow 出片（按 follow-video 的「还没有视频」问）。不写文字步骤的卡，也不拿素材库里的音频当练习。

## 5. 给老大的说明（每个选项一句）
网上找到的只是给老大看的候选：他同意了才用 follow 出片，出好片才排进计划。
格式：「<名字> · <时长> · <来源>：<为什么适合>」。
例：「睡前身体扫描 · 15 分钟 · B 站：女声慢，从脚到头，适合躺下前做。」

## 6. 记录候选
只记选中的：放进 `learn.media` 的 `works`，标上 `"good":0`，每次打「有用」加 1。被打「没用」的从 `works` 挪到 `avoid`，写一句原因。没选中的候选不记。

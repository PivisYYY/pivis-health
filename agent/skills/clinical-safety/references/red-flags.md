# 红旗清单

级别：**急** = 现在打 120 或去急诊；**尽快** = 今天或明天看医生；**门诊** = 1–2 周内约；**观察** = 先自我照护，加重就升级。
只给级别、动作、科室，不说病名。

## 1. 心脏和呼吸
| 情况 | 级别 | 去哪 |
|---|---|---|
| 胸痛、胸口压着或紧，尤其是活动时出现，或者连到左臂、下巴、后背，伴出汗、恶心 | 急 | 120 |
| 突然喘不上气，休息也不缓解；嘴唇发紫 | 急 | 120 |
| 晕倒，或者运动中差点晕倒 | 急 | 急诊 |
| 心慌伴头晕、胸闷、快要晕倒 | 急 | 急诊 |
| 一侧脸、手臂或腿突然无力或发麻，说话含糊，看东西突然模糊或重影 | 急 | 120（记下发生时间） |
| 这辈子最剧烈的头痛，突然出现 | 急 | 120 |
| 偶尔心跳漏一拍，没有别的不舒服 | 门诊 | 心内科 |
| 爬楼、快走比以前明显更喘，持续几周 | 门诊 | 心内科或呼吸科 |
| 手表上的血氧数（工具输出）反复偏低，同时觉得喘或头晕 | 尽快 | 呼吸科（没有症状就只记录，不下结论） |

## 2. 睡眠
| 情况 | 级别 | 去哪 |
|---|---|---|
| 开车或操作机器时犯困、打盹 | 尽快（当天起不开车） | 睡眠门诊。CBT-I 的窗口先放宽 |
| 打鼾很响、被人说夜里憋气，夜里憋醒、喘不上气 | 门诊 | 睡眠门诊或呼吸科（睡眠监测） |
| 几天几乎不睡却不觉得累，特别亢奋、话多、花钱多 | 尽快 | 精神科。睡眠限制立刻停 |
| 情绪一激动就突然腿软、肌肉没力；白天无法控制地睡着 | 门诊 | 神经科或睡眠门诊 |
| 睡梦中拳打脚踢、把梦演出来，伤到自己或别人 | 门诊 | 神经科或睡眠门诊 |
| 傍晚或夜里腿很不舒服、总想动，动了才好 | 门诊 | 神经科或睡眠门诊 |
| CBT-I 认真做了 6–8 周（日记 ≥ 5/7），还是没有改善 | 门诊 | 睡眠门诊 |
| 失眠伴情绪持续低落两周以上 | 门诊（有自伤念头就按第 4 节） | 精神科或心理门诊 |

## 3. 体重和进食（包括 GLP-1 类药物）
| 情况 | 级别 | 去哪 |
|---|---|---|
| 持续剧烈的腹痛，可能连到后背，伴或不伴呕吐 | 急 | 急诊 |
| 吐得喝不进水，尿很少、头晕、口干 | 急 | 急诊 |
| 眼睛或皮肤发黄，尿像浓茶 | 尽快 | 消化科或急诊 |
| 右上腹痛，吃油腻后加重，伴发烧 | 尽快 | 急诊或普外科 |
| 脸、嘴唇、喉咙肿，呼吸困难（打针或吃药后） | 急 | 120 |
| 心慌、手抖、出冷汗、发晕，在用降糖药时 | 急（先吃糖，再就医） | 急诊或内分泌科 |
| 持续恶心、便秘超过一周，影响吃饭 | 门诊 | 告诉开药的医生 |
| 暴食后催吐、用泻药或利尿剂控制体重 | 门诊（有晕倒、心慌就是急） | 精神科或心理门诊 |
| 很怕吃东西，体重掉得很快还在节食 | 门诊 | 精神科或营养科 |
| 没在减重，体重却持续下降 | 门诊 | 内科 |

## 4. 情绪和心理
| 情况 | 级别 | 去哪 |
|---|---|---|
| 有伤害自己或结束生命的念头，有具体打算或工具，或者已经伤害了自己 | 急 | 120 或 110，同时给热线 |
| 有轻生念头，但没有具体打算 | 尽快 | 热线 12356，尽快去精神科 |
| 情绪低落、没兴趣，持续两周以上，影响吃饭、睡觉、工作 | 门诊 | 精神科或心理门诊 |
| 惊恐发作（心慌、喘不上气、觉得要死了），第一次出现 | 急（先排除心脏） | 急诊 |
| 焦虑反复，影响工作和睡眠 | 门诊 | 精神科或心理门诊 |
| 越来越靠酒或药物来应付 | 门诊 | 精神科或成瘾门诊 |
热线（24 小时）：全国心理援助热线 12356；北京心理危机研究与干预中心 010-82951332；希望 24 热线 400-161-9995。

## 5. 运动和伤病
| 情况 | 级别 | 去哪 |
|---|---|---|
| 运动中胸痛、晕、心跳乱 | 急 | 见第 1 节 |
| 受伤时听到「啪」一声，马上肿，不能承重 | 尽快 | 骨科或运动医学科 |
| 关节卡住或打软，肢体麻木无力 | 尽快 | 骨科 |
| 疼痛超过 3 天不见好，或者越来越重；夜里疼 | 门诊 | 骨科或运动医学科 |
| 运动后尿色像可乐，肌肉剧痛、肿 | 急 | 急诊 |

## 6. 其他
| 情况 | 级别 | 去哪 |
|---|---|---|
| 高烧伴脖子僵硬、意识不清 | 急 | 120 |
| 发烧 ≥ 3 天不退 | 尽快 | 发热门诊或内科 |
| 尿检试纸某项 ++ 以上（照片读数） | 门诊 | 「建议就医检查」，不解释原因 |
| 大便带血或黑便 | 尽快 | 消化科 |

## 7. 工具数据怎么用
- 工具里的 `see_doctor` 级别：只说「建议就医检查」，带上工具给的指标和日期，不猜原因。
- 单项数据异常但人没有不舒服：不升级成「急」，记录，按对应 skill 处理（比如 stress-recovery）。
- 人有症状、数据却正常：按症状分级，不能用数据来排除。

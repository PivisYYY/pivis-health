# 补剂：证据和安全

老大问「要不要吃 X」「蛋白粉 / 肌酸 / 鱼油 / 维生素 D / 镁 / 褪黑素有没有用」时读这一页。流程和红线在 `../SKILL.md`；伤病、训练、睡眠期间怎么吃在 `recovery-nutrition.md`。
证据等级：**A** 指南、系统综述 / 荟萃分析一致；**B** 单项 RCT 或较强观察研究；**C** 机制或经验。

---

## 1. 原则（每次都按这个答）
1. **食物优先**：补剂只在有明确缺口（吃不够、化验缺）或明确目标（例如力量训练想加肌酸）时考虑 [1]。
2. **先安全后效果**：在用药（尤其抗凝药、降糖药、甲状腺药、抗抑郁药、GLP-1 类）、有肝肾病、怀孕或备孕、哺乳、准备手术、未成年 → **先问医生或药师**，P-Health 不替他判断能不能一起吃。
3. **P-Health 不推荐药**：褪黑素、处方剂量的维生素 D、治病用的任何东西，都是医生的事。补剂只讲证据和研究里用的量（这是营养信息，不是处方），不主动推销，老大自己决定。
4. 回答结构同 AGENTS 2.5：**判断**（值不值得、对他这种情况有没有用）→ **依据**（证据等级）→ **处方**（真要用：什么形式、研究常用量、什么时候吃、怎么看质量）→ **验证**（看什么、多久）→ **红旗**（哪些情况先问医生）。
5. 老大开始吃了什么，记 `profile.meds`（「自己在吃肌酸 / 鱼油」），之后解读体重、睡眠、化验时考虑进去。

## 2. 常问的补剂
| 补剂 | 对谁可能有用 | 证据结论 | 研究里常用的量 | 安全和注意 | 等级 |
|---|---|---|---|---|---|
| 蛋白粉（乳清、大豆、豌豆） | 饮食吃不够蛋白质：没胃口、用 GLP-1 类药物、外卖为主、康复期 | 和食物蛋白一样有效，只是方便；吃够了没有额外好处 [2] | 1 勺约 20–30 g 蛋白质（记 meal-log 约 1 掌）| 肾病先问医生（健康人高蛋白不伤肾 [3]）；乳糖不耐选分离乳清或植物蛋白；选有检测的品牌 | A |
| 肌酸（一水肌酸） | 做力量训练的人、想保肌肉的减脂期、年纪大的人 | 配合力量训练明显增加力量和瘦体重 [4] | 每天 3–5 g，什么时间吃都行，不需要「冲击期」[4] | **头几周体重会多 0.5–2 kg 的水**（解读体重时要说）；会让化验的肌酐偏高，体检前告诉医生；肾病先问医生；健康人长期使用是安全的 [4] | A |
| 维生素 D | 很少晒太阳（室内工作、冬季）、年纪大、化验偏低的人 | 健康人常规补不能预防癌症、心血管病或骨折 [5][6][7]；化验缺的人由医生补 | 中国成人推荐摄入 10 μg（400 IU）/ 天（65 岁以上 15 μg），可耐受上限 50 μg（2000 IU）/ 天 [8] | 超过上限长期吃有高钙风险；要不要化验、补多少听医生 | A |
| 鱼油（omega-3） | 一周吃不到 2 次鱼的人 | 先吃鱼（每周至少 2 次水产品 [9]）；健康人吃鱼油不能减少心血管事件 [10]；每天 ≥ 1 g 时房颤风险略升 [11]；对关节和肌肉恢复的证据弱 | 研究常用每天约 1 g（EPA + DHA） | 在吃抗凝 / 抗血小板药、要做手术 → 先问医生 | A（预防无效）/ C（恢复） |
| 镁 | 饮食里坚果、全谷、绿叶菜很少的人 | 对失眠只有低质量证据，效果小 [12] | 补剂来源的镁每天不超过 350 mg（上限）[13] | 容易拉肚子；肾功能不好不要自己吃；和某些抗生素、骨质疏松药要隔开 → 问药师 | C |
| 褪黑素 | —— | 慢性失眠指南不建议用 [14]；对倒时差、作息整体后移有用，但剂量和时间很讲究 | **不给量**：归医生 | P-Health 不推荐；先做 CBT-I（cbti）；想用请老大问医生或药师，尤其在吃别的药、怀孕、开车前 | B |
| 咖啡因（咖啡、提神饮料） | 训练前提神 | 训练前约 60 分钟摄入能提高表现 [15] | 研究用 3–6 mg / kg；每天总量 ≤ 400 mg、单次 ≤ 200 mg 对健康成人没有安全顾虑 [16] | **最后一杯离上床至少 8 小时**（recovery-nutrition.md）；心慌、焦虑、反酸的人少用 | A |
| 胶原蛋白 / 明胶 + 维生素 C | 肌腱、韧带康复期 | 运动前吃能提高胶原合成指标 [17]；对疼痛和功能的改善只有小型研究 [18] | 研究用 10–15 g 明胶或胶原肽 + 约 50 mg 维生素 C，康复训练前 30–60 分钟 | 安全；别指望它代替负荷训练 | C（结局） |
| 钙 | 奶和豆制品吃得很少的人 | 先从食物补（奶 300–500 g / 天）[9] | 中国成人推荐摄入约 800 mg / 天（不同年龄略有差别，食物 + 补剂合计）[8] | 有肾结石史、在吃甲状腺药 → 先问医生；和铁、甲状腺药隔开 | B |
| 电解质饮料 | 热天打球或运动 > 60–90 分钟、出汗很多的人 | 补水 + 钠，帮助维持表现、减少抽筋相关的脱水 [19] | 按标签；平时不需要 | 平时当饮料喝就是多余的糖 | B |
| 铁、维生素 B12 | 化验缺的人；纯素食者（B12） | 只在缺的时候有用 | 听医生 | 不缺时补铁有害 | A |
| 复合维生素 | 吃得很单一、长期节食的人 | 吃得正常的人补了不能预防心血管病和癌症 [20] | 按标签，不超过上限 | 别和其他单项补剂叠加超量 | A |

## 3. 不推荐的
| 东西 | 为什么 | 等级 |
|---|---|---|
| 支链氨基酸（BCAA） | 蛋白质吃够了没有额外作用 [21] | B |
| 氨糖、软骨素（关节保健品） | 关节退变指南明确不推荐 [22] | A |
| 燃脂片、左旋肉碱、酵素、排毒茶、减肥茶 | 没有减重证据；不少减肥类产品被查出偷加药物、泻药或利尿剂 | C |
| 网上「海外代购」成分不明的产品 | 剂量和成分无法核实 | C |

## 4. 怎么选、怎么看质量
- 国内的保健食品看「蓝帽子」标志和批准文号；运动补剂优先选有第三方禁用物质检测的（如 Informed Sport、NSF Certified for Sport）[1]。
- 一次只加一样，至少 4–8 周再判断有没有用；有不舒服就停，并告诉医生。
- 和药一起吃有疑问时，统一说：「这个要问开药的医生或药师，P-Health 不判断药和补剂能不能一起吃。」

# 减重与饮食的专业依据

回答减重、饮食、体重波动、用药期间怎么吃之前先读这一页。执行流程（路线、称重、照片反馈、周复盘）在 `../SKILL.md`，份量怎么说在 `meal-feedback.md`。
体重、步数等数字只来自 `./pivis-health`；这里只放原理和判据。不评价任何药物剂量。

证据等级：**A** 指南或多 RCT / 系统综述一致；**B** 单项 RCT 或较强观察研究；**C** 机制或经验。C 级要直说证据弱。

---

## 1. 体重为什么变（先懂这个）

| 要点 | 说明 | 等级 |
|---|---|---|
| 长期看是能量差 | 吃进去少于消耗，体重才会持续下降；没有哪种「神奇食物」或时间点能绕开 [1] | A |
| 单天是水 | 一天上下 0.5–1.5 kg 主要是水、盐、糖原和肠道内容物：咸的一顿、多吃主食、便秘、喝酒、月经周期、练完腿（肌肉水肿）都会让第二天变重 | A |
| 所以看 7 天平均 | 每天称、看 7 天均值的周变化；单天涨不代表胖了 | B |
| 速度 | 一般建议每周减体重的 0.5–1%；初期（尤其开始用药或少吃主食时）前 1–2 周掉得快，多是水 [1] | A |
| 平台期 | 体重下降后消耗也下降，原来的吃法差距变小；连续 2–3 周 7 天均值不动才算平台 | A |

## 2. 吃什么最重要（按优先级）

1. **蛋白质够**：减重期每天约 **1.2–1.6 g / kg 体重**（有力量训练、想保肌肉可到 1.6–2.0）[3][9]。分到每餐，每餐一掌心（约 20–40 g）。蛋白质最顶饱，减重时最保肌肉。
2. **蔬菜和膳食纤维**：每天膳食纤维 25–30 g 以上和体重、血糖、心血管更好相关 [7]；做法上就是每顿半盘蔬菜、主食里换一部分全谷杂豆。
3. **少吃超加工食品**：同样能随便吃的情况下，超加工饮食每天多吃约 500 千卡 [5]。零食、甜饮、加工肉、外卖重油重酱是最常见的超标来源。
4. **主食控量，不必戒**：控制份量和种类（全谷、杂豆、薯类优先），低碳和低脂长期减重效果差不多，选自己能坚持的 [1]（A）。
5. **饮料**：含糖饮料、奶茶、果汁算一顿加餐；酒精每克 7 千卡、还会让人多吃、压低第二天的恢复（stress-science.md）。
6. **水**：每天 1.5–2 L 起，运动和天热加；口渴、尿色深就是不够。

## 3. 怎么吃（时间和方式）

| 问题 | 结论 | 等级 |
|---|---|---|
| 轻断食 / 16:8 比普通少吃更好吗 | **不更好**。同样的总热量，限时进食和普通少吃一年后效果没有差别 [4]；适合的人可以用它来少吃，但不是必须 | A |
| 晚饭吃晚了会胖吗 | 总量决定体重；但晚饭离睡觉太近会影响睡眠（cbti 的 sleep-science.md：睡前 3 小时吃完），且晚上更容易吃多 | B |
| 一定要吃早饭吗 | 不一定；看自己哪种吃法总量更好控制 | A |
| 吃得慢有用吗 | 有：慢吃、每口放下筷子，更早有饱感，尤其用 GLP-1 类药物时 | B |
| 每顿的顺序 | 先蔬菜和蛋白质，再主食：饱得更早、餐后血糖更平稳 | B |

## 4. 运动和减重

- 单靠运动减重效果有限，**主要作用是保住肌肉、防反弹、改善代谢和心肺** [1][8]。
- 减重期间每周 **≥ 2 次力量训练**（training-coach），配合足够蛋白质，能让减掉的更多是脂肪 [3]。
- 长期维持体重的人共同的做法：规律称重、每天活动（步数）、吃法稳定 [8]。

## 5. GLP-1 / GIP 类药物期间（司美格鲁肽、替尔泊肽等）

- 这类药通过降低食欲、延缓胃排空减重，临床试验里一年多下来平均减重约 15–20%（替尔泊肽高剂量组约 20%）[10][11]。**剂量、加减量、停药都只听医生的。**
- 风险点是**减掉的里面肌肉占比不低**：所以蛋白质优先（每餐先吃蛋白质）、力量训练每周 ≥ 2 次是用药期最重要的两件事（A-）。
- 吃得少时最容易缺：蛋白质、水、膳食纤维（便秘）。没胃口也先保证喝水和蛋白质（豆浆、牛奶、蛋、酸奶都算）。
- 常见反应：恶心（少量多餐、慢吃、少油、别吃到撑）、便秘（水 + 蔬菜 + 活动）、反酸（睡前 3 小时不吃）。持续严重的告诉医生。
- 红旗（马上就医）：持续剧烈腹痛（可能放射到后背）、吐到喝不进水、尿少头晕、眼睛皮肤发黄、过敏肿胀、呼吸困难 —— 见 clinical-safety。
- 停药后体重容易回升：生活方式（蛋白质、力量、称重、步数）要在用药期间就养成。

## 6. 常见问题决策表

| 老大说 | 结论 | 为什么 | 等级 |
|---|---|---|---|
| 「今天突然重了 1 公斤」 | 正常波动，看 7 天平均；想一下昨天是不是咸、吃主食多、喝酒、便秘、练了腿 | 第 1 节 | A |
| 「两周没掉了」 | 先查执行（称重天数、照片里主食和加餐、步数、力量），再看是不是真平台（7 天均值 2–3 周不动） | 第 1 节 | A |
| 「晚上饿得受不了」 | 白天蛋白质和蔬菜是否够；晚饭加一份蛋白质；需要就安排一个小加餐（无糖酸奶、蛋、豆腐干），不硬扛到暴食 | 第 2 节 | B |
| 「吃多了一顿，明天要少吃吗」 | 不补偿，下一顿正常吃 | 补偿性节食容易引出下一次暴食 | B |
| 「要不要吃代餐 / 减肥茶 / 酵素」 | 代餐偶尔替代一顿可以，不顿顿替代；减肥茶多是泻药利尿，不用；酵素没有减重证据 | | A |
| 「能喝酒吗」 | 尽量不喝；喝就少量、和饭一起、睡前 3 小时停，算进当天的量 | 第 2 节 | A |
| 「蛋白粉要喝吗」 | 饮食能吃够就不必；吃不够（没胃口、用药期）是方便的补充 | [3] | A |
| 「要不要算热量」 | 不必；P-Health 用手掌份量和盘子比例，照片不估热量 | meal-feedback.md | C |

## 7. 什么时候建议就医

- 每周减重持续超过 1 kg（尤其用药期）、头晕乏力、心慌；第 5 节的红旗。
- 暴食后催吐、怕吃东西、体重已经偏低还在节食 → clinical-safety「体重和进食」。

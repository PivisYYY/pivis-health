# 饭的照片怎么反馈

## 1. 份量用手和碗来说（不写克数和热量）
| 类别 | 一份大约 | 减重时一顿的目标 |
|---|---|---|
| 主食（米饭、面、馒头、粥） | 一拳头 ≈ 小半碗米饭 | 一拳头；晚饭可以减半 |
| 蛋白质（肉、鱼、蛋、豆腐、虾） | 一掌心（厚度和大小都像手掌），或 2 个鸡蛋 | 一掌心 |
| 蔬菜（不含土豆、玉米、南瓜这类淀粉菜） | 一捧 | 两捧，大约占半盘 |
| 油和酱（炸、红烧、勾芡、沙拉酱） | 一拇指 | 尽量少 |
| 饮料 | — | 水、茶、黑咖啡；含糖饮料和奶茶算加餐 |
盘子比例：半盘蔬菜，¼ 蛋白质，¼ 主食。

## 2. 反馈格式（四句以内，summary 写第一句）
1. **吃了什么，结构怎样**：「米饭一碗 + 红烧肉小半盘 + 青菜一小撮，主食和油偏多，蔬菜少。」
2. **对目标的影响**（一句）：「这样的晚饭吃饱了也容易超，蛋白质也不够撑到睡前。」
3. **下一顿怎么改**（一个具体动作）：「明天午饭米饭减到一拳头，加一份蔬菜。」
4. 有做得好的就说一句：「蛋白质够了，这个保持。」

## 3. 常见情况
| 照片里 | 反馈要点 |
|---|---|
| 外卖盖饭 | 饭只吃一半，先吃菜和肉；下次备注少饭、少油 |
| 面条、粉 | 主食偏多，蛋白质少；加一个蛋或一份肉，面留三分之一 |
| 火锅、烧烤 | 先涮肉、豆腐和蔬菜，少蘸酱，主食和丸子类少点 |
| 奶茶、甜点 | 算一顿加餐；当天不补偿，下次换小杯、少糖 |
| 很少（几口） | 在用 GLP-1 类药物、没胃口时常见：先保证蛋白质和水，不要硬吃，也不要不吃 |
| 宵夜 | 离上床不到 2 小时会影响睡眠；做 CBT-I 的话，提醒一句睡前别吃太饱 |
| 酒 | 一句说清：会影响减重和睡眠，尽量不喝；不评价药物 |

## 4. 不说的话
- 不说热量、卡路里、克数、「大约 xxx 大卡」。
- 不说「你不该吃这个」「吃坏了」这类评判。
- 不建议用饿一顿、明天少吃、多跑步来抵消。
- 不说某种食物能「刮油」「排毒」「降糖」。

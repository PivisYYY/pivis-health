# 饭的照片怎么反馈

流程（read_image → 估份量 → `meal-log` → 回复 → todo-update）在 `../SKILL.md` 第 3 步；每道菜算几份、藏起来的油怎么估在 `food-portions-cn.md`。

## 1. 四种手掌份量（P-Health 只估这个）
| 份量 | 是什么 | 对应 `portions` 字段 |
|---|---|---|
| 1 掌 | 熟的肉、鱼、虾、豆腐，大小和厚度像自己的手掌（不含手指）；其他蛋白质食物按 food-portions-cn.md 折算（例：鸡蛋 3 个 ≈ 1 掌） | `protein_palms` |
| 1 捧 | 单手捧起的熟主食：米饭、面、粥里的米、土豆、玉米、红薯、水果也算这里 | `carb_hands` |
| 1 拳 | 拳头大小的蔬菜（不含土豆、玉米、南瓜、莲藕、山药这类淀粉菜） | `veg_fists` |
| 1 拇指 | 整根拇指大小的油脂：炒菜油、坚果、花生酱、沙拉酱、麻酱、肥肉的油 | `fat_thumbs` |
- 份量可以写 0.5、1.5 这样的半份；估不准时宁可按中间值，并把 `confidence` 降一档。
- **克数和热量只由 `meal-log` 换算成范围**，P-Health 不自己说「这碗饭 200 克」「这顿 750 大卡」。
- 一顿的目标抄 `nutrition-targets` 的 `per_meal`。还没算出来时用常见起点（C）：男性每顿约蛋白质 2 掌、蔬菜 2 拳、主食 1–2 捧、油 1–2 拇指；女性约蛋白质 1 掌、蔬菜 1–2 拳、主食 1 捧、油 1 拇指。盘子比例：半盘蔬菜、¼ 蛋白质、¼ 主食。

## 2. 回复格式（四句以内，summary 写第一句）
1. **吃了什么、各几份**：「米饭 2 捧 + 红烧肉约 1 掌（偏肥）+ 青菜半拳，油大概 3 拇指。」
2. **工具给的范围**（照抄 `meal-log` 输出，标明是估的）：「这顿蛋白质大约 20–30 克、热量大约 750–950 千卡（照片估的）。」
3. **做得好的一件**（有就说）：「有蔬菜，这个保持。」
4. **下一顿一个具体改法**（对照 `per_meal` 和当天累计）：「明天午饭主食减到 1 捧，加 1 掌鱼或鸡胸。」
- `confidence:"low"` 时第二句加「这张估得比较粗」。合餐按三分之一估的，说出来：「按你吃了三分之一估的，多了少了告诉我。」
- 当天累计（工具输出里有）离目标差得多，就把第 4 句换成今天剩下那顿怎么补：「今天蛋白质还差不少，晚饭吃 2 掌。」

## 3. 常见情况
| 照片里 | 反馈要点 |
|---|---|
| 外卖盖饭 / 套餐 | 饭常有 3 捧以上：只吃一半；先吃菜和肉；下次备注少饭、少油 |
| 面条、粉、麻辣烫 | 主食偏多、蛋白质少：加一个蛋或 1 掌肉，面留三分之一；汤别喝完（油和盐都在汤里） |
| 火锅、烧烤 | 先涮肉、豆腐和蔬菜；蘸料是隐藏的油（麻酱、油碟）；丸子、午餐肉、主食少点 |
| 炸的、干锅、地三鲜、红烧 | 油至少 3–5 拇指：同样的菜下次换蒸、煮、白灼或清炒 |
| 早餐油条、煎饼、包子 | 主食和油多、蛋白质少：加鸡蛋、牛奶或豆浆 |
| 奶茶、甜点、饮料 | 算一顿加餐，记进去；当天不补偿，下次换小杯、少糖或无糖 |
| 很少（几口） | 用 GLP-1 类药物、没胃口时常见：先保证蛋白质和水，不硬吃，也不要不吃 |
| 宵夜 | 离上床不到 2–3 小时会影响睡眠；做 CBT-I 的提醒一句别吃太饱；想吃就小份蛋白质（牛奶、酸奶、蛋） |
| 酒 | 写进 dishes 和 note；一句说清会影响减重和睡眠；工具没算酒就说「酒的热量没算进去」 |
| 受伤 / 康复期的饭 | 重点看蛋白质够不够（recovery-nutrition.md），别在这时候大幅少吃 |
| 练完的那顿 | 有 1–2 掌蛋白质 + 主食就对了；不用因为练了就额外多吃甜的 |

## 4. 不说的话
- 不自己估克数和热量；工具的数只说范围，不说「刚好 812 大卡」这种单一精确数。
- 不说「你不该吃这个」「吃坏了」这类评判。
- 不建议用饿一顿、明天少吃、多跑步来抵消。
- 不说某种食物能「刮油」「排毒」「降糖」「燃脂」。

## 5. summary 写法（todo-update 用，一句话）
- 「米饭 2 捧 + 鸡腿 1 掌 + 青菜 1 拳 · 主食偏多」
- 「牛肉面一大碗（主食约 3 捧）+ 牛肉半掌 · 蛋白质少」
- 「火锅 · 合餐按三分之一估 · 麻酱约 3 拇指」

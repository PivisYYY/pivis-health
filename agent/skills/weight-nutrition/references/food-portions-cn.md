# 中餐和外卖的手掌份量

看饭的照片、或 Psir 口头说吃了什么时，用这一页把食物换成四种手掌份量（掌 = 蛋白质、捧 = 主食、拳 = 蔬菜、拇指 = 油脂，定义见 `meal-feedback.md` 第 1 节），再交给 `meal-log` 换算成范围。**这里只有份量，不写克数和热量**：那些只由服务器换算。
下面的折算是营养师常用的经验值（C 级，蛋白质和脂肪的相对多少参照中国食物成分表 [3]）：照片里碗大碗小、做法油重油轻，按第 1、5 节调整；Psir 纠正过的以他为准（第 9 节）。

---

## 1. 从照片判断份量
| 看什么 | 怎么用 |
|---|---|
| 参照物 | Psir 的手出现在画面里最准；其次筷子（约 24 cm）、手机（约 15 cm）、易拉罐、一次性勺子 |
| 家用饭碗（口径约 11–12 cm） | 平平一碗米饭 ≈ 1.5–2 捧；冒尖 ≈ 2.5 捧；小碗（约 10 cm）平碗 ≈ 1–1.5 捧 |
| 面碗 / 汤面大碗（口径约 18–20 cm） | 一碗面 ≈ 3–4 捧；面馆「大碗」4 捧以上 |
| 外卖盒 | 圆形米饭盒 ≈ 2–3 捧；盖饭盒底下的饭 ≈ 3–4 捧；长方形 750 ml 盒装满的炒菜按内容拆（菜 2–3 拳 / 肉 1.5–2 掌） |
| 家常圆盘（约 20–25 cm）| 铺满一层的炒青菜 ≈ 2–3 拳（整盘，合餐要算 Psir 吃了多少） |
| 拍摄角度 | 俯拍会低估堆起来的高度和碗的深度：碗看不到底就按碗型补；侧拍能看厚度 |
| 合餐 | 一桌几个人、几盘菜：估 Psir 吃下去的那份；拿不准先问（SKILL 第 3 步），或按三分之一并把 `confidence` 设成 low |
| 吃之前还是吃之后 | 吃剩的照片：从原来的份量里扣掉剩下的 |
| 看不到的 | 汤里的面、饭底下的饭、被菜盖住的油：按做法估（第 5 节），`confidence` 降一档 |

## 2. 主食（捧）
| 食物 | 份量 |
|---|---|
| 米饭 | 见第 1 节碗的大小 |
| 粥 1 碗 | 0.5–1 捧（稀的取低） |
| 馒头、花卷 1 个（拳头大） | 1.5–2 捧 |
| 包子 1 个（中等） | 肉包 1 捧 + 0.3 掌 + 0.5 拇指；素包 1 捧 + 0.5 拇指 |
| 饺子 / 馄饨 10 个（中等） | 2 捧 + 肉馅 0.5–1 掌 + 1–2 拇指（猪肉馅取高；煎饺再加 1–2 拇指） |
| 汤面、米粉、米线 1 碗 | 3–4 捧 |
| 炒饭、炒面、炒粉 1 份 | 3–4 捧 + 3–4 拇指 |
| 面包 2 片 | 1.5 捧 |
| 土豆 1 个（拳头大）/ 红薯 1 个（中等）/ 玉米 1 根 | 1.5 捧 / 1.5–2 捧 / 1–1.5 捧 |
| 淀粉菜：土豆丝、藕片、山药、南瓜、芋头、粉丝、豌豆、玉米粒 | 算捧，不算拳：一人份约 1 捧 |
| 水果：苹果、橙子 1 个 / 香蕉 1 根 / 葡萄一小串 | 各约 1 捧 |
| 杂豆（红豆、绿豆）粥或饭 | 按捧算 |

## 3. 蛋白质（掌）
| 食物 | 份量 |
|---|---|
| 鸡胸、瘦肉、鱼片、牛排，手掌大小和厚度 | 1 掌 |
| 鸡腿 1 个（带骨，常见大小） | 约 1 掌 |
| 鸡翅 2 个 | 0.5 掌 + 1 拇指 |
| 鸡蛋 1 个 | 0.3 掌（3 个 ≈ 1 掌）；煎蛋再加 0.5 拇指 |
| 虾 8–10 只（中等，去壳） | 1 掌 |
| 整条清蒸鱼（合餐） | Psir 吃下去的肉通常 1–1.5 掌 |
| 北豆腐（老豆腐）手掌大一块 / 嫩豆腐同样大 | 0.6 掌 / 0.3 掌 |
| 豆腐干 2 块 / 豆浆 1 杯（约 300 ml） | 各约 0.3 掌 |
| 牛奶 1 盒（250 ml） | 0.3 掌 + 0.5 捧 + 0.5 拇指（全脂；脱脂不算拇指） |
| 无糖酸奶 1 杯 / 希腊酸奶 1 杯 | 0.3 掌 / 0.5 掌 |
| 肥的肉：五花、红烧肉、排骨、腊肠、培根、肥牛卷，看着 1 掌 | 蛋白质只算 0.5 掌 + 油 2–3 拇指 |
| 丸子、午餐肉、火腿肠 2–3 个 | 0.3 掌 + 1 拇指 |
| 蛋白粉 1 勺 | 约 1 掌 |

## 4. 蔬菜（拳）
| 食物 | 份量 |
|---|---|
| 炒青菜、西兰花、菌菇、豆芽、番茄、黄瓜、茄子、青椒，一人份 | 1–1.5 拳（整盘家常圆盘 2–3 拳） |
| 外卖配菜一小格 | 0.5 拳 |
| 凉拌菜一碟 | 1 拳 + 1 拇指 |
| 汤里的菜（紫菜蛋花汤、青菜汤） | 0.3–0.5 拳 |
| 荤菜里的配菜（宫保鸡丁的黄瓜、青椒肉丝的青椒） | 按看到的量，通常 0.5–1 拳 |
- 土豆、南瓜、藕、山药、玉米不算蔬菜，算主食（第 2 节）。

## 5. 藏起来的油和酱（拇指）
中餐的油大多在做法里，照片看不全，**按做法估一人份**：
| 做法 | 一人份大概 |
|---|---|
| 蒸、煮、白灼、清炖 | 0–0.5 拇指 |
| 清炒、快炒 | 1–2 拇指 |
| 红烧、糖醋、鱼香、宫保、京酱 | 2–3 拇指（还有糖） |
| 干煸、干锅、地三鲜、油焖、过油肉 | 3–5 拇指 |
| 油炸（炸鸡、锅包肉、天妇罗、炸串） | 3–5 拇指 |
| 水煮鱼、毛血旺、麻辣香锅（吃进去的部分） | 3–6 拇指 |
| 凉拌（香油、红油） | 1–2 拇指 |
| 火锅：麻酱 1 小碗 / 油碟 / 红油锅底 | 约 3 拇指 / 2–4 拇指 / 每份菜再加 0.5–1 拇指 |
| 沙拉酱、花生酱 1 勺；坚果一小把（掌心） | 1 拇指；约 2 拇指 |
**照片里的信号**：
- 盘底积着一层油、汤面浮着红油 → 再加 1–2 拇指。
- 菜表面发亮反光 → 炒菜油偏多，按上一档估。
- 勾芡（亮、稠的汁）→ 有油也有淀粉，拇指 +1。
- 茄子、豆腐、蘑菇、土豆丝很吸油：看着不油也按上一档。
- 盖饭汤汁多 → 饭吸了油，拇指 +1–2。

| 肉夹馍 | 0.7 掌 + 2 捧 + 2 拇指 |

| 饼干 3–4 块 / 蛋糕 1 块 / 冰淇淋 1 支 | 1 捧 + 1 拇指 / 1.5 捧 + 2–3 拇指 / 1 捧 + 1–2 拇指 |

## 8. 点菜和外卖怎么选
| 场景 | 怎么选 | 等级 |
|---|---|---|
| 原则 | 少盐少油、控糖限酒；先有蛋白质和蔬菜，再配主食 [1] | A |
| 点菜 | 先挑做法：蒸、煮、炖、白灼、凉拌 > 清炒 > 红烧 / 糖醋 > 干锅 / 干煸 / 油炸；每 3 道菜里至少 1 道是蔬菜 | C |
| 外卖盖饭 / 套餐 | 备注「少饭、少油、酱汁分装」；饭只吃一半；加一份青菜或蛋 | C |
| 面馆 | 选汤面而不是拌面 / 炒面；加蛋或加肉；面留三分之一；汤别喝完 | C |
| 麻辣烫 / 香锅 | 多拿蔬菜、豆腐、鲜肉片；少拿丸子、午餐肉、粉面；选清汤或骨汤 | C |
| 火锅 | 清汤或鸳鸯锅；蘸料用蒜泥、醋、葱、小米辣加一点香油，麻酱少一点；先肉和菜后主食 | C |
| 烧烤 | 瘦肉串、鸡胸、鱼、蔬菜串；少五花、肥肠、烤馒头片 | C |
| 早餐 | 鸡蛋 + 牛奶 / 豆浆 + 一份主食（包子、全麦面包、玉米）；油条煎饼偶尔 | C |
| 便利店 | 鸡胸肉、茶叶蛋、无糖酸奶、玉米、饭团、沙拉，少甜饮和炸物 | C |
| 食堂 | 先打蔬菜，再打一份蛋白质，饭打一拳大小 | C |
| 应酬 | 先吃几口菜和蛋白质再喝酒；每杯酒配一杯水；主食少吃或不吃，不要第二天补偿 | C |
- 餐馆和外卖的一份往往比家里做的热量更高、更油 [2]（B），所以外卖按第 5 节的上限估油。

## 9. Psir 纠正份量时
- 「我家的碗是小碗」「那盘我只吃了几口」「我没吃饭」：本次回复按他说的重估份量并说明；以后同类按他的来，记 `correction.nutrition.<主题>`（例：`{"rule":"Psir 家里饭碗是小碗，一平碗米饭 ≈ 1 捧"}`），按 growth-memory「Psir 纠正你时」。
- 已经记进 `meal-log` 的一餐目前没有改的命令：不要重复记一遍；跟 Psir 说「这顿按你说的应该是 X 份，今天的合计会偏高 / 偏低一些」，周复盘时把这个偏差考虑进去。

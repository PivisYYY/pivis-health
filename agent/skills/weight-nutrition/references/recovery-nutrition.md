# 为康复、训练、睡眠怎么吃

Psir 受伤 / 在康复、练完或要打球、问睡前能不能吃、咖啡和酒怎么喝时读这一页。目标数字（热量、蛋白质范围、手掌份量）先跑 `./pivis-health nutrition-targets`，这里只放原理和做法；份量说法见 `meal-feedback.md`，补剂见 `supplements.md`。康复流程在 `../../rehab-coach/SKILL.md`，睡眠时间线在 cbti。
证据等级：**A** 指南、系统综述 / 荟萃分析一致；**B** 单项 RCT 或较强观察研究；**C** 机制或经验。

---

## 1. 受伤和康复期（组织愈合、保肌肉）

| 要点 | 做法 | 依据 | 等级 |
|---|---|---|---|
| 早期别大幅节食 | 受伤后头 1–2 周、固定或术后：热量按 `kcal_target` 的下限到维持之间，不再往下压；之后康复进入力量期再恢复减脂缺口 | 愈合和保肌肉都要能量；能量长期不够会伤骨、拖慢恢复 [1][2][3] | B |
| 练得少了怎么减 | 少的那部分从主食里减（每天约 −1 捧），**蛋白质和蔬菜不减**；甜饮零食先砍 | 训练量下降时碳水需求下降，蛋白质需求不降 [1] | B–C |
| 蛋白质往上限走 | 按 `nutrition-targets` 的 `protein_g` 上限；**分 4 顿左右、每顿约 0.3–0.4 g / kg（多数人 1.5–2 掌）** | 少动时肌肉对蛋白质的反应变差（「合成抵抗」），需要更多、更均匀 [1][4][5] | B |
| 睡前一份蛋白质 | 当天蛋白质不够时，睡前 1–1.5 小时一小份（牛奶 / 无糖酸奶 / 豆浆 1 杯，或蛋，约 0.3–0.5 掌）| 配合训练能增加肌肉合成 [6][7]；小份不影响睡眠 | B |
| 选「好用」的蛋白质 | 奶、蛋、肉、鱼、大豆制品；素食者把豆类和谷类搭配 | 亮氨酸多、吸收好 [8] | A |
| 胶原 + 维生素 C（肌腱、韧带） | 想试的话：康复训练前 30–60 分钟（supplements.md） | 提高胶原合成指标，对结局的证据弱 [9] | C |
| 维生素 D 和钙 | 骨的问题（应力损伤、骨折）、很少晒太阳：请 Psir 问医生要不要化验；钙先从奶和豆制品补 | [2] | B–C |
| 酒先停 | 康复早期和练后当晚不喝 | 酒精压低练后的肌肉合成 [10]，影响睡眠（第 3 节） | B |
| 不需要「消炎食谱」 | 整体吃好（蔬菜、鱼、全谷、少超加工）就够；没有哪种食物能「消炎止痛」 | [1] | C |
| 肌酸 | 固定期保肌肉的证据不一致；健康人可以考虑，先看 supplements.md 的安全条 | [11] | C |
- Psir 怕「不练会胖」：讲清楚少吃主食和甜的就够，蛋白质反而要多，体重看 7 天均值。

## 2. 训练恢复（力量、网球、跑步）

| 要点 | 做法 | 依据 | 等级 |
|---|---|---|---|
| 一天总量最重要 | 先把每天的蛋白质和热量范围吃到，再谈时间 | 「练后窗口」的作用主要来自总蛋白质 [12] | A |
| 每顿均匀 | 每顿 1–2 掌蛋白质（约 0.3 g / kg），隔 3–4 小时 | 4 × 中等量比 2 × 大量或 8 × 小量更好 [5][8] | A–B |
| 练后那顿 | 练后 2 小时内一顿：1–2 掌蛋白质 + 1–2 捧主食 + 蔬菜 | [8][13] | A |
| 练前 | 练前 1–3 小时一顿正常饭（少油、少粗纤维）；来不及就练前 30–60 分钟一个香蕉或一杯酸奶 | [13] | B |
| 碳水跟着练的量走 | 技术练习、轻松活动：主食取目标下限；每天约 1 小时中等强度：主食取中间偏上；减脂期把主食放在练前、练后两顿 | 碳水需求随训练量变化 [13] | A |
| 长时间打球（> 90 分钟）或热天 | 每小时补约 30–60 g 碳水（运动饮料、香蕉）+ 水，出汗多的要有钠 | [13][14] | A |
| 补水 | 练前后各称一次：每少 1 kg，补 1.25–1.5 L；平时看尿色（淡黄为宜） | [13][14] | A–B |
| 晚上练 | 练后晚饭照吃，但离上床 ≥ 3 小时；傍晚以后不喝含咖啡因的练前粉 | 第 3 节 | B |
| 酸痛 | 没有补剂能明显加快；睡够、蛋白质够、时间 | [1] | B |

## 3. 睡眠

| 要点 | 做法 | 依据 | 等级 |
|---|---|---|---|
| 大餐离上床 ≥ 3 小时 | 晚饭时间按今晚时间线排（cbti）；`nutrition-day` 会给最后一顿离上床多久 | 太晚太饱加重反酸、拖慢入睡 [15] | B |
| 咖啡因截止 | **最后一杯离上床至少 8 小时**（简报「今晚时间线」的咖啡截止照抄）| 睡前 6 小时的大剂量咖啡因仍让睡眠少 1 小时以上 [16]；综合研究建议一杯咖啡至少提前约 8.8 小时 [17] | A–B |
| 咖啡因来源 | 美式 / 滴滤一大杯、拿铁、浓茶、奶茶（茶底）、可乐、能量饮料、练前粉、黑巧克力都算；每天总量 ≤ 400 mg [18] | — | A |
| 酒 | 让人更快睡着，但后半夜睡得碎、做梦睡眠少，第二天静息心率高、HRV 低；**睡前 3–4 小时停**，减脂和康复期最好不喝 | [19][24] | A–B |
| 上床晚的人 | 晚饭到上床隔 5 小时以上容易饿：计划一个小加餐（离上床 ≥ 1 小时，牛奶 / 酸奶 / 蛋 / 豆浆），别临睡前吃泡面、烧烤这种大份 | [6][15] | C |
| 睡得少会多吃 | 睡眠被压缩时平均每天多吃约 385 千卡，饥饿感更强 [20][21] | 睡眠是减重计划的一部分 | A |
| 睡前喝水 | 夜里起夜多：睡前 2 小时少喝 | cbti | C |
| 「助眠食物」 | 牛奶、香蕉、猕猴桃、酸樱桃：证据很弱，不当睡眠方法；晚饭里的高升糖主食在睡前约 4 小时吃，小样本里入睡快一些 [22] | — | C |

## 4. 喝酒速查
- 指南：成年人如饮酒，一天酒精不超过 15 g [23]。约等于一罐 450 ml 的 4% 啤酒、一杯 150 ml 的 12% 葡萄酒，或 35–50 ml 白酒（不到一两）。
- 对 Psir 目标的影响一句话说清：减重（热量 + 吃得更多）、睡眠（后半夜碎）、恢复和康复（肌肉合成下降）、第二天 HRV。
- 应酬时：先吃几口蛋白质和菜；每杯酒配一杯水；离上床 3–4 小时停；第二天不补偿，照常吃。
- 在用降糖药或 GLP-1 类药物：喝酒有低血糖等风险，请 Psir 问医生（clinical-safety）。
- 记一餐时酒写进 `dishes` 和 `note`，不折算手掌份量。

# 减重与饮食

## 什么时候用
- 老大说要减重、问体重为什么不动、要定目标。
- 收到称重卡、饭的照片卡的【待办提交】，或者老大在对话里直接发饭的照片。
- 老大提到 GLP-1 类药物期间的饮食、恶心、便秘、没胃口。
- 每周复盘（减重项目的周日卡）。

饭的反馈怎么写、份量怎么说，见 `references/meal-feedback.md`。

## 怎么做

### 1. 定路线（目标和速度）
1. `context-list --scope pref.viz.weight` 看有没有已经定好的路线。
2. 没有就用 question 卡问：目标体重（number，kg），每周减多少（options：0.25 kg / 0.5 kg / 0.75 kg）。**数字只用老大自己说的。**
   - 你给的建议只说原则：「一般建议每周减体重的 0.5%–1%，在用药的话以医生说的为准。」不替老大算具体数。
   - 老大要的速度比每周 1 kg 还快：说明风险（掉肌肉、胆结石、反弹），建议先问医生，路线上还是按他定的记。
3. 按 AGENTS 第 8 节记：`context-record --scope pref.viz.weight --payload '{"rule":"目标 <X> kg，每周减 <Y> kg","target":<X>,"start":<起点>,"start_date":"<日期>","rate_kg_week":<Y>}'`。起点用 `facts` 的 `weight_latest.kg` 和它的日期。
4. 预览：`./pivis-health viz --metric weight --kind route`。输出里有 `fallback_from` 就如实说明。对话里发 viz 卡，回 receipt，effective 写「页面一两分钟后自动换上」。

### 2. 称重习惯
- 每天或每周至少 3 次，早上上完厕所、吃喝之前，同一台秤，穿得一样少。
- 看周趋势，不看单天：一天上下 1 kg 左右是水分、盐、排便，不代表胖了或瘦了。
- 收到体重的【待办提交】：照 AGENTS 第 6 节「收到数字记录」做，跟 `weight_latest` 比一句。不评价药物和剂量。
- 单天涨了：只说「单天波动正常，看这周的趋势」，不加补偿任务。

### 3. 饭的照片
1. 先 `read_image`。不是饭、看不清，就退回 scheduled 请老大重拍（AGENTS 第 6 节）。
2. 按 meal-feedback.md 写：吃了什么 → 主食、蛋白质、蔬菜大概各多少（用「一碗」「一掌心」「半盘」）→ 一句话说对减重目标的影响 → 下一顿的一个具体调整。
3. `todo-update` 写 summary（一句话）和 `"status":"done"`。**不写热量、克数或任何估出来的数字。**
4. 同一个问题连续 3 次出现（比如晚饭主食都偏多），记进 `learn.nutrition`，周复盘时谈。

### 4. 每周复盘
1. `./pivis-health compare --metric weight --baseline prev_week`，抄 `recent.avg`、`baseline.avg`、`change`。有「样本少于 3 天」就说只能当参考。
2. 对照路线：只拿 `change`（负数表示减了）和 `rate_kg_week`、1 kg 比大小，不另外算。
   | 情况 | 动作 |
   |---|---|
   | 减的量达到 `rate_kg_week`，且不超过 1 kg | 保持，肯定一件做到的事 |
   | 连续 2 周减的量没达到 `rate_kg_week` | 先查执行：称重天数、照片里主食偏多的次数、步数（`compare --metric steps`）、力量训练次数。只改一处（比如晚饭主食减到半碗），plan 卡确认 |
   | 连续 2 周每周减了超过 1 kg | 提醒老大告诉医生（在用药时尤其要说），检查蛋白质够不够、力量训练有没有做 |
   | `change` 是正数（涨了） | 不责备，不加补偿。查一件最可能的原因（应酬、睡得差），定一个下周的小改动 |
3. 按 habit-coach 数称重卡、照片卡做到几天，按 growth-memory 写本周学到的。

### 5. 用 GLP-1 类药物期间
- **剂量、加量、减量、停药、换药都听医生的。** P-Health 不评价剂量，也不建议漏打或改时间。老大问剂量，就说「这个要问开药的医生」。
- 吃法：少量多餐，慢慢吃，七分饱就停；每顿先吃蛋白质和蔬菜，再吃主食；少吃油腻和大份；多喝水；酒尽量不喝。
- 蛋白质每顿一掌心，力量训练每周至少 2 次（training-coach），帮着保住肌肉。
- 恶心、便秘、没胃口：记下来（`learn.nutrition`），并提醒老大复诊时告诉医生。没胃口也要保证喝水和蛋白质。
- 红旗：持续剧烈腹痛（可能连到后背）、吐得喝不进水、尿很少或头晕、眼睛或皮肤发黄、脸或喉咙肿、呼吸困难 → **马上就医**，按 clinical-safety 处理。
- 打针提醒：老大要才加。卡上只写「按医嘱打针」，不写剂量。

## 规则与红线
1. 体重数字只来自 `facts`、`compare`、`viz` 和老大记的称重；照片不估热量，也不估克数。
2. 不做极端节食：不建议一天只吃一顿、断食超过一天、只吃单一食物、代餐顿顿替代正餐、泻药、利尿剂、催吐。
3. 吃多了不补偿：下一顿正常吃就行，不加运动惩罚，不让第二天少吃。
4. 不评价药物和剂量；不说「某种食物能治什么」。
5. 出现暴食后催吐、怕吃东西、体重掉得太快还在节食、晕倒：按 clinical-safety 的「体重和进食」处理。
6. 饭的照片卡默认不写 when，不推送。老大要提醒才写（他要的不算进上限）。

## 成长
- `life.diet`：吃饭时间、外卖还是自己做、最难控制的、医生交代的事。
- `learn.nutrition`：`{"rule":"应酬后第二天体重会高，三天内回落，不用补偿","evidence":"近 3 次应酬后的称重（记录卡）"}`。
- `pref.viz.weight`：路线。老大改目标或速度时，合并后重新记。

# 架构与开源范围

## 当前状态

本次发布仅建立项目骨架与说明。这里描述的是从既有私有技术实践提炼的目标结构，不代表这些实现已经在本仓库中提供。

## 目标数据流

```text
健康数据采集端（Apple Health / HealthKit）
  → 私有传输与请求认证
  → 批次格式校验与幂等导入
  → 原始批次归档 + SQLite 标准化存储
  → 可读笔记投影与确定性计算
  → 数据质量门禁 / 可行动变化筛选
  → 按需报告或已授权的私人提醒
```

## 分层约束

| 层 | 后续整理范围 | 边界 |
|---|---|---|
| collector | 采集协议与采集端接入说明 | 不公开个人设备配置、签名证书或实际导出 |
| backend | 校验、幂等、删除记录、提交回执、存储与投影 | 收到请求不等于数据已提交；回执应与请求原文对应 |
| analysis | 本地日期归属、睡眠去重与分桶、异常筛选 | 先检查数据质量；缺失不作生理结论；规则不作诊断 |
| reports | 可视化与按需输出 | 不内置真实个人报告，不默认自动推送 |
| agent | 可选的 Agent、调度与私人渠道适配 | 计算与表达分离；数据和笔记不能变成执行指令 |
| examples / tests | 合成样本与隔离回归 | 不从个人数据生成样本，不连接生产健康库 |

## 逐步补充

1. 数据契约与最小导入/存储实现。
2. 睡眠计算与数据质量回归测试。
3. 合成示例与可复现的安装、运行说明。
4. 可选 Agent 集成与可视化。

顺序仅为整理方向，不是发布时间承诺。每部分代码公开前分别检查隐私、依赖许可和真实执行结果。

## 本次不包含

- 现有生产部署、私人配置、历史数据库或原始导出。
- 已完成的手机 App 开源包或可安装二进制。
- 已通过验收的开源端到端流程。
- 对疾病风险、身体年龄或临床效果的验证声明。
